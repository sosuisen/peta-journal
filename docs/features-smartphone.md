# スマホ版の機能

iPhone版とAndroid版のアウトライナーのテストを要約した、ユーザー目線の機能の一覧である。UIの操作と入出力を書き、内部の仕組みは書かない。節は`storymap-smartphone.md`のアクティビティに沿って分ける。

2026-11-27時点のテストから作った。

両方の版にある機能は、そのまま書く。片方の版にしかない機能は、もう片方で作るToDoとして`- [ ]`で書き、まだない版を「（Android版にない）」のように頭に付ける。

## Dropboxとつなぐ

### サインインする

- 入れたばかりのアプリは、「Sign in to Dropbox」のボタンだけを出す。サインインの前は、今日のジャーナルを作らない
- サインインのあとの最初の同期が終わると、今日のジャーナルが開き、検索の入力欄とメニューが出る
- メニューの「Sign out」でサインアウトすると、メニューは消え、「Sign in to Dropbox」のボタンが出る
  - 取り込んだページは、そのまま読める
  - サインアウトのあとは、同期しない。次にサインインすると、Dropboxのファイルを初めから取り直す
- [ ] （Android版にない）サインインでは、Dropboxにファイルの読み書きの権限だけを求める
- [ ] （Android版にない）サインインの前は、検索の入力欄も出ない
- [ ] （iPhone版にない）サインインの前は、上端のバーも出ない
- [ ] （iPhone版にない）ブラウザでサインインを終えてアプリに戻ると、同期が始まる。サインインは、アプリを開き直しても残る
- [ ] （iPhone版にない）サインアウトのあとは、アプリが前に出ても、前のサインインは戻らない

### 同期する

- アプリが前に来ると同期する
- アプリでページを作ったり書いたりすると、少し待ってから同期し、そのページがDropboxに上がる
  - キーボードが語を変換している間は、同期は始まらない。変換が終わってから待ち、同期する
- 同期が動いている間は、メニューの「Sign out」を使えない
- 同期に失敗すると、知らせが出る
  - 通信できないときは「Sync failed: no connection」、ほかの理由では「Sync failed」とだけ出る
  - 知らせの「Try again」で、同期をやり直せる
  - 失敗したあとのメニューには、「Sign in to Dropbox」が出る
- 開いているページがダウンロードで変わると、編集中の項目の入力欄にも、ほかの端末が書いた文が出る
  - ただし、編集中の項目にこちらで打った文があれば、その文が残る
- [ ] （Android版にない）同期の間は、「Downloading」のダイアログで待たせる。終わると、ダウンロードしたページが見える
- [ ] （Android版にない）同期の失敗は、吹き出しで伝える。失敗したあとのメニューには、「Sync」「Sign in to Dropbox」「Sign out」がある
- [ ] （Android版にない）「Try again」を押しても、つながらなければ同じ知らせが出る
- [ ] （iPhone版にない）後ろへ回るときも、書いたものを上げるために同期する。端末を回したときなど、画面を作り直すだけのときは同期しない
- [ ] （iPhone版にない）メニューの「Sync」で同期する。同期のあと、Dropboxのページが検索で見つかる。アプリのフォルダーで変わったページは、次の同期でDropboxに上がる
- [ ] （iPhone版にない）アプリが前に出たときの同期では、ファイルを運ぶ間、進み具合がダイアログに出る（例: 「Downloading 2 of 5」「Uploading 1 of 2」）
  - 運ぶファイルがまだ分からない間は、ダイアログは出ない
  - 編集のあとの同期では、ダイアログは出ない。進み具合は、ページの上の知らせに出る
- [ ] （iPhone版にない）同期の知らせ（例: 「Syncing…」）は、ページの上端の近くに、右へ寄せて出る
- [ ] （iPhone版にない）同期が動いている間は、メニューの「Sync」も押せない
- [ ] （iPhone版にない）項目を編集している間も、メニューを開ける。開いても、編集は続き、キーボードは消えない
- [ ] （iPhone版にない）失敗の知らせには、理由の長い言葉は出ない。失敗したあとの「Sign in to Dropbox」で、Dropboxが受け付けなくなったサインインをやり直せる
- [ ] （iPhone版にない）開いているページがダウンロードで変わると、画面に触れなくても新しい項目が出る。項目の文だけが変わったときも、編集している間のほかの項目も同じである
- [ ] （iPhone版にない）編集中の項目がほかの端末で書き換わると、カーソルは同じ文字数の位置に残り、続けて打てる

## ページを読む

### ページを開く

- アプリは、前に表示していたページで開く。なければ、今日のジャーナルで開く
- 検索の入力欄
  - 取り込んだページが結果に出る。選ぶと、そのページが開く
  - 入力した名前のページがなければ、作る結果が出る。選ぶと、そのページができて開く
  - 作れない名前（例: `a:b`）では、ページを作らず、訳を「OK」だけのダイアログで知らせる
  - 「today」と打つと、今日のジャーナルを開く結果が出る
- 今日のボタンは、今日のジャーナルを開く。なければ作る
  - 今日のページで下に続く過去の日付は、今日の日付と同じ大きさで出る
- 上端のバーに、戻るボタンと進むボタンがある
  - 戻るで前のページが開き、進むで戻る前のページが開く
  - 戻る先も進む先もないときは、ボタンは出たまま押せない
- [ ] （Android版にない）サインインの前で前のページもなければ、何も開かない。最初の同期のあとに、今日のジャーナルが開く
- [ ] （Android版にない）今日のページを下までスクロールすると、前の日が読み足される
- [ ] （Android版にない）起動して今日のジャーナルだけが開いているときも、戻ると進むは押せない
- [ ] （iPhone版にない）前のページが消えていたときも、今日のジャーナルで開く
- [ ] （iPhone版にない）アプリを離れて開き直しても、すぐに開く
- [ ] （iPhone版にない）ページを2つ開くと戻るが押せ、戻ると進むが押せる

### リンクをたどる

- ページへのリンクに触れると、そのページが開く
  - まだないページへのリンクでは、そのページができて開く
- タグに触れると、そのタグのページが開く
- Webへのリンクに触れると、ブラウザで開く。`mailto:`など、http以外のリンクも、開く先に渡る
- `assets`のファイルへのリンクに触れると、そのファイルが開く。名前の大文字と小文字は問わない
  - ファイルがなければ、ないことを知らせる
- [ ] （Android版にない）タグに触れると、タグのフォルダーの下にあるページが開く
- [ ] （Android版にない）`assets`のファイルは、アプリの中で開く。ないことの知らせは、次のリンクに触れると消える
- [ ] （iPhone版にない）`.md`への相対リンクでも、そのページが開く
- [ ] （iPhone版にない）`assets`のファイルは、端末のほかのアプリで開く
  - ほかのアプリは、ファイルを読むことだけができる
  - ファイルの種類は拡張子で決まる。拡張子が大文字でもよい。種類が分からなければ、どのアプリでも選べる
  - 開けるアプリがなくても、アプリは落ちない
  - ファイルがなければ「No file yet: assets/none.pdf」のように知らせ、何も開かない

### 装飾付きで読む

- 項目は装飾つきで出る。Markdownの記号は出ない
  - 見出しは、レベルに応じた大きさになる
- コードブロックは、書かれたとおりの行で出る。表は、セルごとに出る
- `assets`の画像は、絵として出る
  - 絵の上の1行目に、代わりの文字（alt）が出る。altがなければ、ファイルのパスが出る
  - 1行目に触れると、その項目の編集になる
  - 絵に触れると、大きく開く。もう一度触れると、閉じる
  - ファイルがまだない画像は、代わりの文字が出る
- タスクは、状態の印を持つ。印に触れると、次の状態へ進む
- 子を隠した項目の点は、大きな薄い円の上に描かれる。子を戻すと、円は消える
- [ ] （Android版にない）見出しは太字になる
- [ ] （iPhone版にない）コードブロックのフェンスの記号は出ない。リストの中のコードブロックも同じで、リストの番号は残る
- [ ] （iPhone版にない）セルの中の文字にも飾りが付く。引用の中の表も同じである
- [ ] （iPhone版にない）画像は、前後の文字の間に出る。名前の大文字と小文字は問わない
  - 空白や日本語の名前の画像も、URLの形で書いた画像も出る
  - ページが幅を決めていれば、その幅で出る。なければ、画像そのものの幅で出る
  - ページが高さを決めていれば、その高さで出る。高さだけなら、幅は画像の形に従う
  - Webの画像は描かず、代わりの文字のリンクになる
  - リストの中の画像も、絵として出る。リストの中のリストでも同じである
- [ ] （iPhone版にない）タスクの印は、まだ始めていない、進行中、済みの3つで、項目の文字と同じ高さにある。印に触れても、編集には入らない
- [ ] （iPhone版にない）点（バレット）は、文字の高さの真ん中にある。見出しでは、大きな文字の真ん中の高さにある

## ページに書く

### 項目を書く

- 項目に触れると、その項目がMarkdownの入力欄になる
  - カーソルは、触れた文字のMarkdownでの位置に置かれる
- 打った文字は、ページのファイルに書かれる
  - アプリが裏に回ると、保存を待っていた文字も、すぐにファイルに書かれる
- 開始記号（例: `>>>`）を打ち終えると、閉じる記号が補われる
- Enterは、カーソルの位置で項目を分け、入力は下の新しい項目で続く
- 項目の先頭でのBackspaceは、前の項目につなぐ。編集はつないだ項目で続き、カーソルはつなぎ目に置かれる
  - つなぎ目の位置では、絵文字を1文字として数える
  - 空の項目では、その項目が消え、前の項目の終わりで編集が続く
  - 先頭より後ろでのBackspaceは、前の1文字を消すだけである
  - ほかの項目が写している項目がつなぐことで消えるときは、先に尋ねる。やめれば項目は残り、進めれば消える
- [ ] （Android版にない）文字の先頭に触れると、Markdownの先頭から書ける
- [ ] （Android版にない）文字の右半分に触れると、その文字の後ろになる。行の右に触れると、行の末尾になる。絵文字も1文字として扱う
- [ ] （Android版にない）文の脇に触れると、いちばん近い行の文字になる
- [ ] （Android版にない）新しいジャーナルの空の項目も、触れて書ける
- [ ] （Android版にない）閉じる記号を補ったあと、カーソルはその間に留まる
- [ ] （Android版にない）Enterの直後に打った文字も、新しい項目に入る。続けて打った2つのEnterも、それぞれ新しい項目を作る
- [ ] （Android版にない）長いページの下端の項目に触れても、キーボードが出て、編集が続く。空の項目でも同じである
- [ ] （Android版にない）画面を横にして、編集中の項目が見えるところから外れても、編集は続き、打った文字が入る
- [ ] （Android版にない）検索の入力欄で打っている間は、キーボードは検索の入力欄から離れない
- [ ] （Android版にない）キーボードのステッカーは、文字の中の絵としては入らない。画像の貼り付けになる
- [ ] （iPhone版にない）ほかの項目に触れると、編集がそこへ移る。前の項目は、飾りの付いた表示に戻る
- [ ] （iPhone版にない）改行の位置では、絵文字を1文字として数える
- [ ] （iPhone版にない）空の子の項目での改行は、項目を1段外へ出す。次の改行で、新しい項目ができる
- [ ] （iPhone版にない）長いページの末尾で改行すると、画面は新しい項目まで動く
- [ ] （iPhone版にない）先頭から文字を選んでいるときのBackspaceは、選んだ文字を消すだけで、項目をつながない
- [ ] （iPhone版にない）最初の項目の先頭でのBackspaceは、何もしない
- [ ] （iPhone版にない）画面のキーボードのBackspaceでも、同じに動く。押し続けても、カーソルは残った文字の末尾にある
- [ ] （iPhone版にない）写されている項目を消すときの問いのボタンは、「Cancel」と「Delete」である

### 貼り付ける

- クリップボードのMarkdownのリストを貼ると、項目になる。1つ目はカーソルの位置に続き、2つ目からは下の新しい項目になる
  - アプリがコピーした親と子は、親と子の形のまま戻る
- クリップボードの画像を貼ると、画像は`assets`フォルダーに保存され、項目にそのリンクが入る
  - 画像は、来たときの名前で保存される。名前がなければ、種類の拡張子の名前になる
  - 同じ名前の画像を2回貼っても、別々のファイルになる
- [ ] （Android版にない）入力欄のメニューの「Paste」で貼る
- [ ] （Android版にない）名前のない画像は`image`の名前になる。拡張子のない名前（写真の`IMG_0001`など）には、種類の拡張子が付く
- [ ] （Android版にない）透明部分のあるHEICの画像（ステッカーなど）はPNGに、透明部分のないHEICの画像（写真）はJPEGに直して保存される
- [ ] （iPhone版にない）文字のメニューの貼り付けでも、実のキーのキーボードのCtrl+Vでも同じである
- [ ] （iPhone版にない）画面のキーボードのクリップボードの候補から入れても、親と子の形のまま戻る
- [ ] （iPhone版にない）文字を選んで貼り付けると、選んだ文字が貼り付けた文字に置き換わる
- [ ] （iPhone版にない）画面のキーボードが入れた画像も、`assets`フォルダーに保存される。画像でなければ、`image`という名前になる

### 道具を使う

- 編集しているときと、項目を選んでいるときに、画面の下に道具が出る
  - 削除の道具はない
- キーボードを閉じる道具は、編集を終える。項目は選ばれたまま残る
  - キーボードを出す道具を押すと、選んでいた項目の編集に戻る
- 項目を動かすパッド
  - 右は字下げ、左は字下げを戻す
  - 上と下は、項目を隣の項目と入れ替える
  - 押し続けると、項目は動き続ける
- カーソルを動かすパッド
  - ←と→は、カーソルを1文字ずつ動かす。絵文字は1文字として数える
  - 項目の先頭での←は前の項目の末尾へ、末尾での→は次の項目の先頭へ移る
  - ↑と↓は、上と下の行へ動かす。最初の行の↑は前の項目へ、最後の行の↓は次の項目へ移る。行の中の位置は変わらない
  - 押し続けると、カーソルは動き続ける
- パッドの形
  - 矢印の絵の上でなくても、角から角への線で4つに分けた範囲が、それぞれの矢印になる
  - 真ん中の3分の1に触れても、何も動かない
- タスクの道具は、項目をタスクにする。押すたびに状態が進む
- 折りたたみの道具は、子を隠すと「Expand」になる。もう一度押すと、子が戻る
  - 子のない項目では押せない
- 元に戻すは最後の変更を取り消し、やり直すはそれをまた行う
- 項目を選んでいる間
  - 選んでいる項目は、色で示される。選び直すと、色も移る
  - 項目を動かすパッドは、選んだ項目を動かす
  - コピーと切り取りの道具が出る。選んだ項目をMarkdownのリストでクリップボードに載せる。切り取りは項目をページから消す。編集しているときは出ない
- 縮める道具を押すと、道具は丸いボタンだけになる。丸いボタンを押すと、道具が戻る
  - 縮めたかどうかは、編集と選択を行き来しても変わらない
- [ ] （Android版にない）道具には、折りたたみ、タスク、項目を動かすパッド、カーソルを動かすパッド、元に戻す、やり直す、縮める、キーボードを閉じる、がある
- [ ] （Android版にない）キーボードを閉じたあと、選ばれた項目の背景に色が付く
- [ ] （Android版にない）タスクの道具の状態は、最後はタスクでなくなる
- [ ] （Android版にない）項目を選んでいる間は、カーソルを動かすパッドの上下で、選ぶ項目が上や下の項目に変わる
- [ ] （Android版にない）項目に触れると、選択は終わり、その項目の編集になる
- [ ] （iPhone版にない）項目を消すのは、空の項目の先頭でのBackspaceである
- [ ] （iPhone版にない）キーボードを閉じると、項目は飾りの付いた表示に戻る
- [ ] （iPhone版にない）字下げのあとも、編集は続く
- [ ] （iPhone版にない）カーソルを動かすパッドは、編集しているときだけ出る
- [ ] （iPhone版にない）項目を選んでいる間は、2つ目のパッドの上下で、選ぶ項目が変わる

### 項目のメニュー

- [ ] （Android版にない）項目を長押しすると、項目のメニューが出る
- [ ] （Android版にない）「Delete」は項目を消す
- [ ] （Android版にない）「Send to Stash」は、項目を、ページの終わりの`# Stash`の見出しの下へ送る
- [ ] （Android版にない）別の項目を見せている項目には、「Remove Transclusion」もある。選ぶと、その項目は空の項目になり、見せていた項目は残る
