# 付箋紙の機能

付箋紙アプリ（macOS・Windows）のテストを要約した、ユーザー目線の機能の一覧である。UIの操作と入出力を書き、内部の仕組みは書かない。節は`storymap-stickies.md`のアクティビティとタスクに沿って分ける。

2026-11-27時点のテストから作った。

両方の版にある機能は、そのまま書く。キーだけが違うときは、「Cmd+N（Windows は Ctrl+N）」のように書く。片方の版にしかない機能は、もう片方で作るToDoとして`- [ ]`で書き、まだない版を「（Windows版にない）」のように頭に付ける。

## 付箋紙を机に並べる

### 付箋紙を開く

- 何も保存されていないときは、ページのない付箋紙が1つ開く
- 前の付箋紙は、次の起動で、ページ、位置、大きさ、色、ズーム、常に手前に表示とともに戻る
- [ ] （Windows版にない）タイトルバーだけにした付箋紙は、次の起動でタイトルバーだけで戻る。ダブルクリックで元の大きさに戻る
- [ ] （macOS版にない）最小化した付箋紙は、次の起動で、最小化する前の位置と大きさで戻る

### 付箋紙を足す

- タイトルバーの新しい付箋紙のボタンと Cmd+N（Windows は Ctrl+N）で、ページのない付箋紙を足す
  - 足した付箋紙は、押した付箋紙の左上隅から少し右下に出る。最後に開いた付箋紙の右下ではない
  - 足した付箋紙は、前の付箋紙にぴったり重ならない
  - スクリーンからはみ出るときは、全体がスクリーンに収まる位置まで戻る
  - スクリーンより大きい付箋紙は、左上の隅がスクリーンの左上の隅に合う。タイトルバーが隠れない
- 付箋紙は、それぞれが自分のページを持つ。1つでページを開いても、ほかの付箋紙は変わらない

### 付箋紙を閉じる

- タイトルバーの閉じるボタンで閉じた付箋紙はなくなり、次の起動でも戻らない。ほかの付箋紙は残る
- 閉じる前に、まだ保存していなかった本文がサーバーに保存される
- アプリを終えても、付箋紙はページと位置を持って、次の起動で戻る。アプリを終えるときも、まだ保存していなかった本文は保存される
- [ ] （macOS版にない）Ctrl+Q でアプリを終える
- [ ] （macOS版にない）Alt+F4 で閉じた付箋紙は、次の起動で戻る

## 付箋紙でページを読む

### ページを開く

- ページのない付箋紙には、検索欄が最初から出ていて、カーソルがそこにある
- 検索欄に入力すると、少しあとにページの候補が出る。下矢印で選んで Enter で開くか、候補をクリックして開く。開くと検索欄は閉じ、文字は消える
  - 候補が出ているときの Escape は候補を隠す
- 作れない名前のページを検索から作ろうとすると、知らせが出る
- 新しいページには、空の項目が1つある
- サーバーがアプリよりあとに上がっても、上がるとページが読み込まれて出る
- [ ] （Windows版にない）タイトルバーの検索のツールで検索欄が出る
- [ ] （Windows版にない）候補がないときの Escape は、検索欄を閉じる
- [ ] （Windows版にない）探し終えて何も見つからなかったときだけ、見つからないと出る
- [ ] （Windows版にない）見つけた文の前後が、ページの名前の下に出る。名前で見つけたページでは出ない
- [ ] （Windows版にない）候補がウィンドウに入りきらないときも、検索欄はウィンドウの中にとどまる
- [ ] （Windows版にない）いま開いているページを選ぶと、検索欄の文字が消える
- [ ] （Windows版にない）ページを開いているときにサーバーにつながっていなければ、そう出る。つなぎ始めは、つないでいる途中と出る。ページのない付箋紙には出ない
- [ ] （macOS版にない）Ctrl+F か検索ボタンで検索欄が出る

### 今日のジャーナルを読む

- 今日のジャーナルの題は、今日の日付に「(Today)」を付けたものである。今日でない日のジャーナルの題は、その日付だけである
- 今日のジャーナルを前の日までスクロールすると、題はその日の日付になり、「(Today)」は付かない。今日まで戻ると、また付く
- 前の日の最初の項目の上に、その日の日付が見出しとして入る
- [ ] （Windows版にない）前の日の日付の見出しの上に、区切り線も入る
- [ ] （macOS版にない）スリープからの復帰と時刻の変更で、日付が変わったかを確かめる。同じ日のうちは、今日のジャーナルは開き直さず、編集中の項目もそのまま残る

### リンクをたどる

- 編集していない項目のウィキリンクをクリックすると、そのページがその付箋紙で開く。Option（Windows は Alt）を押しても同じである
- ハッシュタグをクリックすると、タグのフォルダーにあるそのタグのページが付箋紙で開く
- Cmd-クリック（Windows は Ctrl-クリック）で、そのページを新しい付箋紙で開く。新しい付箋紙は、たどった付箋紙の左上隅から少し右下に出る。たどった付箋紙のページは変わらない
- Shift-クリックで、そのページを Web 版でブラウザに開く。付箋紙のページは変わらない
- 外へのリンクと assets のファイルへのリンクは、ブラウザで開く。項目は編集にならず、ページもそのままである
- 戻ると前に開いたページがまた開き、進むと戻る前のページに戻る。履歴は付箋紙ごとにあり、次の起動ではいま開いているページが戻る
- [ ] （Windows版にない）編集中に Cmd+O で、カーソルのあるウィキリンクのページを付箋紙で開く
- [ ] （Windows版にない）タイトルバーの戻ると進むの矢印は、行き先があるときだけ押せる。フォーカスのない付箋紙では、見えない矢印の場所を押しても戻らない

### 装飾付きで読む

- 編集していない項目は、Markdown の記号なしで装飾付きで出る。文字の色は、編集中の項目と同じである
- 見出しは、大きな太字で出る
- リストの項目と引用の中は、右に寄る。中身のないリストの項目も、印は出る
- 区切り線は、線で出る
- 太字、斜体、取り消し線、下線、マーカー、伏せ字、上付き、下付き、コードの字体で出る。上付きと下付きは小さな文字になる
- 表は、セルごとに枠のある格子で出る。見出しの行は太字である。行のない表は何も出ない
- assets の画像は、絵として出る
  - 届くまでは、代替の文字が出る。代替の文字がなければ、ファイルの名前が出る
  - 大きさを求めない画像は、付箋紙の幅に合わせる。元の大きさより大きくはならない
  - 幅か高さを求めた画像は、それに合わせ、縦横の比を保つ
- 本文のない項目は、何も出ない
- [ ] （macOS版にない）引用の中は薄い文字になる

## 付箋紙に書く

### 項目を書く

- 表示した文字に触れると、その項目の編集に入り、触れた文字の位置にカーソルが入る
  - 区切り線に触れると、その項目の先頭にカーソルが入る
  - 編集中の項目をクリックすると、カーソルはクリックした文字のそばに移る
  - 文字の横（空の項目でも）をクリックしても、その項目の編集に入る。付箋紙が開いた直後のクリックでも同じである
- 打った文字は、少しあとにサーバーに保存される
- Enter で、カーソルの位置で項目を分ける。カーソルは新しい項目の先頭に移る
- Shift+Enter で、項目を分けずに項目の中で改行する
- 先頭での Backspace で、項目を前の項目につなぐ。カーソルはつなぎ目に置かれる
- 末尾での Delete で、次の項目をつなぐ
- 上矢印は、前の項目へ同じ位置のまま移る。最後の行での下矢印は、次の項目へ移る
  - 2行ある項目の2行目や、末尾の改行のあとの空の行での上矢印は、項目の中で上の行へ動く
- 先頭での左矢印は前の項目の末尾へ、末尾での右矢印は次の項目の先頭へ移る
- 開始記号を打ち終えると、閉じる記号が補われる
- 本文が1行の見出しである項目は、編集中も見出しの大きさの太字で出る。記号はそのまま見える
- 項目から検索欄へ移り、また項目に戻ると、項目はもう一度編集中になる
- サーバーの拡張が確認を求めると、質問が出る。「いいえ」では何も起きず、「はい」で先へ進む
- [ ] （Windows版にない）編集中の項目を Shift-クリックすると、カーソルからクリックした文字までが選ばれる
- [ ] （Windows版にない）変換中の文字は、画面が描き直されても消えない
- [ ] （Windows版にない）Enter のすぐあと、項目が分かれる前に打った文字や Enter も、新しい項目に入る

### 構造を整える

- Tab で項目を字下げし、Shift+Tab で字上げする。文字は入らない
- Shift+Option+上下（Windows は Shift+Alt+上下）で項目を上下に動かす。カーソルはその項目に残る
- Cmd+上（Windows は Ctrl+上）で子の項目を隠し、Cmd+下（Windows は Ctrl+下）で表示する。切り替えではない。カーソルは文の中で動かない
- Ctrl+Enter で項目をタスクにし、押すたびに状態を進める。文字は入らない
  - タスクの印をクリックすると、状態が進む。項目を編集していなくてもよい
- 編集中でない空の項目には、バレットが見えない。文字のある項目と、編集中の項目には見える
- [ ] （Windows版にない）子を隠した項目のバレットは、二重の円である
- [ ] （Windows版にない）Cmd+Enter でも、項目をタスクにし、状態を進める
- [ ] （Windows版にない）タスクの前にもバレットが出て、そのあとにタスクの状態が並ぶ。進行中は横線の入った箱、完了はチェックの入った箱で出る

### 取り消す

- Ctrl+Z で元に戻し、Shift を足してやり直す
- ほかで表示されている項目を消すときは、確認を求められる
- [ ] （Windows版にない）メニューの「取り消す」と「やり直す」でもでき、項目の中でいつも選べる
- [ ] （macOS版にない）消すときの確認は、OK で消える。確認のダイアログでの Enter は取り消しになり、何も消えず、選択も残る

### 選んで扱う

- 最初の行での Shift+上で、その項目を選ぶ。Shift+上下で選択が広がり、Escape で選択が消える
- 項目の文字から別の項目までドラッグすると、またいだ項目が選ばれる
- 選んでいるあいだの Backspace か Delete で、選んだ項目を消す
- 選んでいるあいだの Shift+Option+上（Windows は Shift+Alt+上）で、選んだ項目を上へ動かす
- 選んでいるあいだの Cmd+C（Windows は Ctrl+C）で、選んだ項目を Markdown としてコピーする
  - 同じ内容の HTML もコピーされる。ウィキリンクとハッシュタグは、Web 版のページを開くリンクになる
- 選択は、項目の文字のクリックで消え、その項目に入力できる。項目の外や項目のないところのクリックでも消える。項目は消えない
- [ ] （Windows版にない）項目の中だけのドラッグは文字を選び、項目は選ばない。付箋紙の下端にかかった項目の中で文字をドラッグしても、スクロールしない
- [ ] （Windows版にない）ドラッグで項目を選んでも、打っていた文字は保存され、選んだ項目を動かしても消えない
- [ ] （Windows版にない）ドラッグ選択のマウスを付箋紙の上端か下端で止めると、その向きへスクロールし、出てきた項目まで選ばれる
- [ ] （Windows版にない）ドラッグ選択のマウスが付箋紙の上の外へ出ると、見えているいちばん上の項目まで選ばれる。まだ見えていない項目は選ばれない
- [ ] （Windows版にない）メニューの「コピー」でもコピーできる
- [ ] （macOS版にない）検索ボタンやタイトルバーのクリックでも、選択が消える

### 貼り付ける

- Cmd+V（Windows は Ctrl+V）で、Markdown のリストを項目に分けて、カーソルの位置に貼る
  - 絵文字のすぐ後ろのカーソルでも、カーソルの位置に貼る
- Shift+Cmd+V（Windows は Ctrl+Shift+V）で、文字をそのまま1つの項目に貼る
- 親と子を選んでコピーし、別の項目の終わりに貼ると、親と子の形のまま戻る
- クリップボードの画像は、サーバーの assets に保存され、カーソルの位置にそのリンクが入る。カーソルが項目を離れると、画像で出る
- [ ] （Windows版にない）メニューの「ペースト」と「ペーストしてスタイルを合わせる」でも貼れる
- [ ] （Windows版にない）Finder でコピーした画像のファイルも貼れる。HEIC の画像は、ブラウザで見られる形に直して保存される。元のファイルは残る
- [ ] （Windows版にない）文字もあるクリップボードでは、画像ではなく文字を貼る。画像でないファイルのコピーでは、画像を貼らない
- [ ] （macOS版にない）画像のファイルをドラッグ＆ドロップで入れられる。元のファイルは残る
  - 編集中の項目に落とすと、落とした文字の位置にリンクが入る。編集していない項目に落とすと、本文の末尾にリンクが入る
  - 落としたファイルの中で、最初の画像だけが入る。画像がなければ、何も入らない
- [ ] （macOS版にない）編集していない項目の右クリックのメニューの「Paste as Transclusion」で、コピーした項目をトランスクルージョンとして貼る

## 付箋紙の見た目を整える

### 色を変える

- 新しい付箋紙は黄色である。9色と、そのあとの透明から、付箋紙の色を選ぶ。今の色には印が付く
- 透明を選ぶと、後ろのウィンドウが透けて見える。色を戻すと、透けなくなる
- 透明な付箋紙は、フォーカスがないとき、書かれた文字だけを見せる。クリックしてフォーカスが戻ると、また出る。色のある付箋紙は、何も隠さない
- [ ] （Windows版にない）透明な付箋紙では、フォーカスがないとき、タイトルバーの名前とツール、バレット、スクロールバー、ウィンドウの影が隠れる。フォーカスのない付箋紙をメニューで透明にしても、すぐに隠れる

### 大きさを変える

- タイトルバーのダブルクリックで、タイトルバーだけに巻き上げる。もう一度で、元の大きさに戻る。上の端と幅は変わらない
  - 紙の上のダブルクリックでは、大きさは変わらない
- ズームすると、項目の文字が大きくなる。縮小すると小さくなる。等倍に戻せる
  - ズームは1回で1割ずつ変わり、30% から 300% までである
- 常に手前に表示すると、付箋紙はほかのウィンドウの上にとどまる。やめると、普通のウィンドウに戻る
- [ ] （Windows版にない）タイトルバーの名前の上をダブルクリックしても巻き上げる。すばやくクリックし続けると、2回目で巻き上げ、4回目で戻る。ウィンドウは大きくならない
- [ ] （macOS版にない）画面いっぱいの付箋紙は、タイトルバーのダブルクリックで元に戻る。巻き上げはしない
- [ ] （macOS版にない）最大化のボタンで画面いっぱいになり、もう一度押すと元に戻る。最小化のボタンで最小化する

### メニューを開く

- タイトルバーの右クリックで、付箋紙のメニューが出る。常に手前に表示する項目と、付箋紙の色が並ぶ
  - 常に手前に表示しているときは、その項目に印が付く
- [ ] （Windows版にない）編集していない項目の右クリックか Control-クリックでも、付箋紙のメニューが出る。項目は編集に入らず、カーソルは元の項目に残る。何も押さないクリックでは出ない

### 道具を隠す

- [ ] （Windows版にない）フォーカスがないときは、タイトルバーの検索のツールと、閉じる・しまう・大きくするボタンが隠れる。フォーカスが戻ると出る。新しい付箋紙のボタンは残る
- [ ] （Windows版にない）タイトルバーだけにしている間は、閉じる・しまう・大きくするボタンと検索のツールが隠れる。元に戻すと出る
