# memoviewの機能

memoview（Windows）のテストを要約した、ユーザー目線の機能の一覧である。UIの操作と入出力を書き、内部の仕組みは書かない。

2026-11-27時点のテストから作った。

## ページの表示

- 項目は、ページの順に1行ずつ出る
  - 折りたたまれた項目の子孫は出ない。そのあとの項目は出る
  - 本文のない項目は、空の行になる
- 行の先頭の印
  - 子のない項目には黒丸が付く。見出しには黒丸が付かない
  - 子のある項目には、黒丸の代わりに折りたたみの矢印が付く。開いているときは下向き、折りたたまれているときは右向きである
- タスク
  - タスクには、黒丸の代わりにチェックボックスが付く。タスクでない項目には付かない
  - 開始も終了もなければTODOで、チェックボックスは空である。開始だけならRUNNINGで、横線が入る。終了があればDONEで、チェックが入る。値が空の時刻は、ないものとして扱う
  - 子のあるタスクには、チェックボックスの左に折りたたみの矢印が付く
- 付箋紙の色が、ページの背景になる
- アクティブでない付箋紙は、スクロールバーを出さない
- ページの代わりに見せる文（案内やエラー）は、HTMLではなく文字のまま出る

## リンクと画像

- ウィキリンクとハッシュタグは、サーバーの設定どおり、PetaJournalのWebアプリのページへのリンクになる
- ページからの相対パスで書かれた画像は、サーバーから読む

## ページでの操作

- ズームを変えられる。倍率は、OSの言語によらず正しく効く
- 折りたたみの矢印をクリックすると、その項目を開いたり折りたたんだりする
- ウィキリンクやハッシュタグをクリックすると、そのページを開く
  - `http`と`https`のほかのURLは開かない

## 付箋紙の設定

- 足した付箋紙は、次に起動しても残る
- 消した付箋紙は、次に起動しても出てこない。ほかの付箋紙は残る
  - 閉じる途中の付箋紙が位置やサイズを保存しても、消した付箋紙は戻らない
