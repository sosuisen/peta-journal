# plans

## Web版の境界のクレート（ADR 079、ADR 080）

- [x] 時計とwindowのAPIで済む画面の操作は、wasmがこなす。
- [x] 破壊的な確認は、質問としてシェルへ渡す。
- [x] 編集欄へのフォーカスと項目までのスクロールは、シェルへ渡す。
- [x] シェルが書いたイベント、キー、入力、ドラッグ、答えは、facetのJSONで読める。
- [x] facetのJSONでないものは、読めない理由とともに断られる。
- [x] 画面の差分は、facetのJSONで書かれ、項目の名前はRustのフィールド名である。
- [x] 行の本文は、本文のHTMLである。
- [x] 境界の型が、TypeScriptの型として書かれる。
- [x] シェルが開いたページは、サーバーから読まれ、答えが来るとシェルに描き直しを知らせる。
- [x] シェルの呼び出しの中で変わった画面は、戻り値の差分で返り、描き直しは知らせない。
- [x] 2つ目の破壊的な確認は、1つ目が答えられるまでシェルに届かない。
- [x] コアが求めたページの移動は、URLを変えてから、そのページを開く。
- [ ] 何も指さないURLは、今日のページに置き換わる。
- [ ] 貼った画像のファイルは、そのままサーバーへ送られる。
- [ ] タイマーは、時間が来るとコアに届き、取り消すと取り消しが届く。
- [ ] サーバーのイベントの流れは、コアに届く。
- [ ] 起動すると、ブラウザに残した並べ方とアトラスのフォルダがコアに戻る。
- [ ] 今の時刻は、シェルに尋ねずに答える。
