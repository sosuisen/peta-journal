## #808 年をまたぐUSの週は新しい年に入る（ADR 072）

- [ ] USの週は、その週の土曜の年に入る。1月1日を含む週が新しい年の第1週である

- [ ] 年の週の数を超える週の最初の日は、求められない（USとISO）

- [ ] 週の名前の番号は1〜53で、54は名前ではない
- [ ] その年にない週のジャーナルは開けない（USとISO）
- [ ] 年をまたぐUSの週へのリンクは、12月と1月の月のジャーナルで新しい年の名前である
