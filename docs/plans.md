## #823 リストの差分と変わったパネル（ADR 076）

### リストの差分
- [x] 同じリストには、操作がない
- [x] 中身の変わった行は、その位置の更新になる
- [x] 新しい行は、その位置への挿入になる
- [x] 消えた行は、後ろの位置から順に削除になる
- [x] 順の変わった行は、移動になる。中身も変わっていれば、続けて更新になる
- [x] 前の行が1つも残らないときは、入れ替えが1つだけになる
- [x] 前も今も空のときは、操作がない
- [x] 操作を順に当てると、前のリストが今のリストになる

### パネル
- [x] 最初の差分は、行の入れ替えと、全部のパネルである
- [x] 何も変わらなければ、差分は空である
- [x] 変わったパネルだけが、差分に入る
- アウトラインのパネルには、行が入らない：`OutlinePanel`に`rows`の欄がないので、型が保証する。テストは書かない

### NativeShell
- [ ] 開いたページの最初の`changes()`は、行の入れ替えと全部のパネルである
- [ ] 続けて呼んだ`changes()`は、空である
- [ ] 入力した本文は、その行の更新として届く

### FFI
- [ ] `client-shell-http`の入口から、差分をbytesで読める
- [ ] `client-shell-embedded`の入口から、差分をbytesで読める
- [ ] 差分の型が、Swift、C#、Kotlinの型として生成される
