## #902 Paste images in the macOS stickies

- [ ] ペーストボードのPNGの画像は、一時フォルダーの自分だけのフォルダーに、同じ中身の`image.png`として書かれる
- [ ] TIFFだけの画像（スクリーンショットなど）は、PNGに直して書かれる
- [ ] Finderでコピーした画像のファイルは、同じ名前と中身で一時ファイルに写され、元のファイルは残る
- [ ] 同じ画像を2回貼っても、別々のファイルに書かれる
- [ ] 文字があるペーストボード（Officeのように、文字と画像を両方載せるアプリ）では、画像を書かない
- [ ] 画像でないファイルのコピー（Finderはアイコンの画像も載せる）では、画像を書かない
- [ ] 画像のファイルを貼ると、サーバーのassetsに保存され、項目にそのリンクが入る。ファイルは保存のあとに消える
- [ ] メニューの「ペースト」（Cmd+V）は、クリップボードの画像を、カーソルの位置にリンクとして貼る
