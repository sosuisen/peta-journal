## #948 EmacsText（ADR 078）

- [ ] 段落のtextは、表示の文字と、その後ろの改行である。飾りのない文字には範囲がない
- [ ] 文字の見た目は、範囲の見た目になる。位置は文字（コードポイント）で数える
- [ ] リンクのある文字は、範囲にリンクを持つ
- [ ] 見出しの段落は、行全体に見出しの深さの見た目を持つ
- [ ] リストの段落の前には、深さの字下げと記号がある。どちらも表示の文字ではない
- [ ] 引用の段落の前には、引用の印がある。表示の文字ではない
- [ ] 区切り線は、表示の文字ではない線である
- [ ] コードブロックの行は、コードの見た目を持つ
- [ ] 画像は、代わりの文字の範囲に画像を持つ。表示の文字ではない
- [ ] 表の升は、列ごとにそろう。升の間の印は、升の後ろの改行の代わりの表示の文字である
- [ ] 表示の文字だけを拾うと、ネイティブと同じ表示の文字になる（どの段落もコードも、textの中の位置がstartと合う）
- [ ] シェルは、行ごとに本文のMarkdownとEmacsTextを送る
- [ ] Lispのプロトコルのファイルに、EmacsTextのフィールドを読む関数と、見た目の名前の一覧がある
