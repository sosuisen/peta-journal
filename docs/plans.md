## #1207 共通のテストを、各シェルが備えているかを確かめる（ADR 089）

- [ ] 共通のテストのファイルがあり、例のファイルを読み、テストの道具が集める場所にあれば、何も出ない
- [ ] 共通のテストに、テストのファイルも`pending`も`excluded`もないシェルは、出る
- [ ] テストのファイルがないと、出る
- [ ] テストのファイルが例のファイルの名前を読んでいないと、出る
- [ ] テストのファイルが、テストの道具の集める場所（`tests`のフォルダー、言語のテストのファイルの名前）の外にあると、出る
- [ ] Rustのテストのファイルは、同じフォルダーの`mod`で読まれていないと、出る
- [ ] `pending`のissueの番号が0だと、出る
- [ ] `test`、`pending`、`excluded`のうち2つ以上を書くと、出る
- [ ] 共通のテストの一覧にない名前を書くと、出る
- [ ] `shell-check common <shell>`は、出たものを書き、何もなければ0、あれば1で終わる
- [ ] リポジトリのルールのあるどのシェルでも、何も出ない（`tests/repository.rs`）
- [ ] 見張り: ルールのあるどのシェルも、共通のテストを回すテストの段を持つか、`pending`である（`scripts/verification.test.mjs`）
