## #949 Emacsの表示モードと編集モード（ADR 077）

- [ ] Emacsは、表示の文字の位置で編集を始められる。シェルは、そのMarkdownの位置をfocusで伝える
- [ ] 打った本文は、そのEmacsTextだけが送り返される
- [ ] pointのない行は、EmacsTextで描かれ、範囲の見た目の色を持つ。Markdownの記号は見えない
- [ ] pointのある行は、本文のMarkdownを色なしで見せる
- [ ] pointが別の行に入ると、その行はMarkdownに、出た行はEmacsTextになる。シェルには、pointの前の表示の文字の数を送る。Rustが足した文字は数えない
- [ ] 答えのfocusで、pointはMarkdownの位置に置かれる
- [ ] 行が書き換わってpointが別の行に移ったときも、その行はMarkdownになる
- [ ] pointのない行は、編集できない
- [ ] pointのある行の更新で、本文が同じなら、行は書き換えられない
- [ ] EmacsTextの行のリンクは、クリックで開く。ページへのリンクはgoを送り、Webのリンクはブラウザーで開く
- [ ] EmacsTextの行の画像は、届いたあとで画像として見える。大きさはリンクの指定に従う
- [ ] 開いたページの画像は、上限を超えても忘れられない
- [ ] Markdownの正規表現の色付けは、なくなる
