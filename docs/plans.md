## Reactのページのプロパティ（#931）

- [x] 日時はUTCとブラウザの時間帯の分とで行き来する
- [ ] プロパティは1行ずつ、名前と値を出す。消せるものだけに×がある

- [ ] 新しい行の×で、保存せずに消す
