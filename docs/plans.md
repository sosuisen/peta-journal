# plans

## #910 拡張Webアプリを`apps/`フォルダから配信する（ADR 073）

### journal-server

- [ ] `apps/{url_fragment}/`のファイルは、`/apps/{url_fragment}/`の下のパスで返る。`--frontend-dir`がなくても返る。
- [ ] `/apps/{url_fragment}/`には、そのアプリの`index.html`が返る。
- [ ] 拡張子のないパスでファイルがないときは、そのアプリの`index.html`が返る。
- [ ] 拡張子のあるパスでファイルがないときは、404が返る。
- [ ] アプリのフォルダがないときは、404が返る。
- [ ] `/apps/{url_fragment}`は、`/apps/{url_fragment}/`へリダイレクトされる。
- [ ] すべてのファイルが`Cache-Control: no-cache`で返る。ハッシュの付いた名前でも同じである。
- [ ] 置いたフォルダは再起動なしで配信され、消したフォルダは再起動なしで404になる。
- [ ] `..`のような名前で、`apps/`の外のファイルは返らない。
- [ ] Web版の画面を配信しているときも、`/apps/`のパスは画面の`index.html`より先に扱われる。
