## #795 見出しの倍率と字下げを、コアがデータで渡す

- [ ] 見出しの段落は、レベルの倍率を持つ。h1からh5は1.6、1.4、1.2、1.1、1で、h6も1。見出しでない段落は1
- [ ] 段落の字下げは、(リストの深さ＋引用の深さ)×1.5em
- [ ] 部品を持つリスト（Entries）の項目と、引用（Quote）は、1段の字下げ（1.5em）を持つ
- [ ] 行は、1行目の倍率を持つ。編集中は、本文全体が1行の見出しのときだけ見出しの倍率になる
