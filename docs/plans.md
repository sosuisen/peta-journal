# #886 閲覧モードで画像の上にtitleを出す（Android、iOS）

titleは画像のalt（`![ここ](url)`）。altが空ならパス（`assets/…`）を出す。

- [ ] Android: 画像の1行目にaltが見え、その下に絵がある
- [ ] Android: altのない画像は、1行目にパスが見える
- [ ] Android: 1行目に触れると、その項目の編集になる
- [ ] Android: ファイルのない画像は、altを1回だけ見せる（今のテストのまま）
- [ ] iOS: 画像の1行目にaltが見え、その下に絵がある
- [ ] iOS: altのない画像は、1行目にパスが見える
- [ ] iOS: 1行目に触れると、その項目の編集になる
