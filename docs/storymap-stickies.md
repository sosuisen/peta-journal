# PetaStickies（付箋紙アプリ）

## 概要（仮）

デスクトップに置く付箋紙で、PetaJournal のページを読み、書く。付箋紙はそれぞれが1つのページを持ち、ジャーナルサーバーにつながる。macOS（`stickies-mac`）と Windows（`stickies-win`）の2つがあり、決まりは Rust のコア（`client-core`、`client-stickies`）に1つだけある。

このストーリーマップは、2026-11-24 時点の付箋紙アプリの仕様から逆算して作った。出典は、`stickies-mac` と `stickies-win` のテストの日本語の説明、`client/libs/client-stickies/src/tests.rs`、`docs/features.md` の付箋紙の節である。

## ペイン（仮）

- 今日やることや、いま書いているページを、ほかの作業の横に出しておきたい。ブラウザのタブに埋もれると見なくなる。
- 付箋紙に書いたことも、ジャーナルのページとして残したい。付箋紙だけの別のメモにはしたくない。
- 付箋紙を並べても、作業の邪魔にはしたくない。使わないときは小さく、目立たなくしたい。

## ユーザーのタイプ（仮）

- 利用者 `#利用者`: macOS か Windows のデスクトップに付箋紙を並べて、ページを読み書きする人。

- 付箋紙を机に並べる #利用者
  - // 出典: stickies-mac の StickyDeskTests、stickies-win の StickyDeskTests と AreaTests、client-stickies の tests.rs
  - 付箋紙を開く
    - 起動すると、前の付箋紙がページ・位置・大きさとともに戻る
      - ^ 何も保存されていないときは、ページのない付箋紙が1つ開く
        - 最小化した付箋紙も、最小化する前の位置と大きさで戻る
  - 付箋紙を足す
    - ＋ボタンと Cmd+N（Windows は Ctrl+N）で、ページのない付箋紙を足す
      - 足した付箋紙は、押した付箋紙の左上隅から少し右下に出る
        - ^ スクリーンからはみ出るときは、全体が収まる位置まで戻る
  - 付箋紙を閉じる
    - 閉じるボタンで閉じた付箋紙はなくなり、次の起動でも戻らない
      - ^ 閉じる前に、保存を待っていた本文がサーバーに保存される
        - アプリを終えても、付箋紙はページと位置を持って次の起動で戻る
          - ^ Windows の Alt+F4 で閉じた付箋紙は、次の起動で戻る
- 付箋紙でページを読む #利用者
  - // 出典: stickies-mac の ShellTests と OutlineScreenTests、stickies-win の ShellTests、docs/features.md の付箋紙の節
  - ページを開く
    - 検索欄に入力し、候補を選んでページを開く
      - ^ ページのない付箋紙には、検索欄が最初から出ている
        - ^ 付箋紙はそれぞれが自分のページを持ち、ほかの付箋紙は変わらない
  - 今日のジャーナルを読む
    - v 今日のジャーナルの題には「(Today)」が付き、前の日へスクロールすると題がその日になる
      - ^ 前の日の最初の項目の上に、区切り線とその日の日付が入る
        - ^ 日付の変わり目とスリープからの復帰で、今日が変わったかを確かめる
  - リンクをたどる
    - ウィキリンクとハッシュタグのクリックで、そのページを付箋紙で開く
      - ^ 外へのリンクは、ブラウザで開く
        - Cmd-クリック（Windows は Ctrl-クリック）でそのページを新しい付箋紙で開き、Shift-クリックで Web 版で開く
          - ^ タイトルバーの矢印とキーで、付箋紙ごとに戻る・進む
  - 装飾付きで読む
    - 編集していない項目は、Markdown の記号なしで装飾付きで出る
      - ^ 見出し、リスト、タスク、表、引用が出る
        - assets の画像が絵として出て、付箋紙の幅に収まる
- 付箋紙に書く #利用者
  - // 出典: stickies-mac の OutlineScreenTests と ShellTests、stickies-win の OutlineScreenTests と ShellTests
  - 項目を書く
    - 表示した文字に触れると、触れた位置にカーソルが入って編集できる
      - ^ 打った文字は、少しあとにサーバーに保存される
        - ^ Enter で項目を分け、Shift+Enter で項目の中で改行し、先頭の Backspace で前の項目につなぐ
          - 開始記号を打ち終えると、閉じる記号が補われる
  - 構造を整える
    - v Tab と Shift+Tab で字下げと字上げをし、Shift+Option+上下（Windows は Shift+Alt+上下）で項目を動かす
      - ^ Cmd+上下（Windows は Ctrl+上下）で子を隠し、表示する
        - ^ 項目をタスクにし、印のクリックで状態を進める
  - 取り消す
    - v Cmd+Z（Windows は Ctrl+Z）で元に戻し、Shift を足してやり直す
      - ^ ほかで表示されている項目を消すときは、確認を求められる
  - 選んで扱う
    - vv Shift+上やドラッグで項目を選び、消す・動かす・コピーする
      - ^ ドラッグが付箋紙の端に来ると、スクロールして選択を広げる
        - ^ 親と子を選んでコピーし、別の項目に貼ると、親と子の形のまま戻る
  - 貼り付ける
    - vv Markdown のリストは、項目に分けて貼る
      - ^ Shift を足した貼り付けは、文字をそのまま1つの項目に入れる
        - ^ 画像は、サーバーの assets に保存して、そのリンクを入れる
          - ^ Windows では、項目のメニューから、トランスクルージョンとして貼る
- 付箋紙の見た目を整える #利用者
  - // 出典: stickies-mac の StickyDeskTests と OutlineScreenTests、stickies-win の StickyTests、client-stickies の tests.rs
  - 色を変える
    - vvv 9色から付箋紙の色を選び、次の起動でもその色で戻る
      - ^ 透明を選ぶと、後ろのウィンドウが透けて見える
        - ^ 透明な付箋紙は、フォーカスがないとき、書かれた文字だけを見せる
  - 大きさを変える
    - vvv macOS では、タイトルバーのダブルクリックで、タイトルバーだけに巻き上げる
      - ^ ズームは、30% から 300% まで、1割ずつ変わる
        - ^ 常に手前に表示する
  - 道具を隠す
    - vvv macOS では、フォーカスがないときは、タイトルバーの道具と、閉じる・しまう・大きくするボタンが隠れる

スライスのゴールは、次のとおりである。ウォーキングスケルトンは、付箋紙を開いて、ページを探して読み、書いた項目がサーバーに残る。毎日使うは、付箋紙を何枚も並べ、今日のジャーナルとリンクでページを行き来し、項目の構造を整えて取り消せる。まとめて扱うは、項目を選んで動かし、コピーと貼り付けでほかのページやアプリとやり取りする。見た目は、付箋紙の色、透明、巻き上げ、ズームで、ほかの作業の横に置きやすくする。

スライスは、新しい利用者が付箋紙を使い込んでいく順である。2026-11-24 時点で、すべてのカードは実装済みである。片方の OS だけのカードは、カードの文に OS の名前を書いた。PetaJournal 全体のストーリーマップは `docs/storymap.md` にあり、付箋紙はそこでは「URL スキームでデスクトップアプリ（付箋）を起動する」の1枚だけである。
