# PetaJournal

## 概要（仮）

ローカルの Markdown ファイルの上に載る、オフラインファーストのアウトライナー。毎日のジャーナルに書いたものが、ページ・リンク・タグ・地図（アトラス）へ育っていく。ジャーナルサーバーを中心に、拡張機能・外部アプリ・AI エージェント・別の PC がゆるくつながる。

これは Web 版（`outliner-react`）とサーバーのストーリーマップで、PetaJournal 全体の地図も兼ねる。ほかのアプリのストーリーマップは、`storymap-emacs.md`、`storymap-smartphone.md`、`storymap-stickies.md` にある。

このストーリーマップは、2026-11-02 時点のフロントエンド（`client`）の仕様から逆算して作った。出典は、コアのテスト（`client/libs/client-core/src/tests/*.rs` の日本語の説明）、E2E テスト（`client/apps/web-app/outliner-react/e2e/tests/*.spec.ts`）、画面のモジュールコメント、`docs/properties.md`、`docs/folder-sync-journeys.md` である。

## ペイン（仮）

- 毎日メモを書く人は、まず「今日」に書き始めたい。ページ名やフォルダを先に決めさせられると、書く前に手が止まる。
- 書いたメモは、数日後には別の文脈（プロジェクトのページ、タスク、別の日）に属している。コピーではなく、移動や参照で動かしたい。
- 考えをまとめるとき、階層のリストだけでは全体が見えない。ページを平面に並べて、まとまりを作りたい。
- データは手元の Markdown に置き、エディタや他のツールからも触りたい。クラウドのサービスに閉じ込められたくない。
- 複数の PC を使う人は、同じフォルダを共有するだけで同期したい。消えたファイルで勝手にページが消えるのは困る。

## ユーザーのタイプ（仮）

- 利用者 `#利用者`: ブラウザでアプリを開いて書く人。ジャーナルとページの持ち主。
- 拡張 `#拡張`: サーバーの API を通して項目やページを作るプログラム。拡張機能（`ext-functions`）、Web アプリ（`client/apps/web-app/todo`）、デスクトップアプリ（`client/apps/webview-app/memoview-win`）。
- AI エージェント `#AI`: MCP でページを探し、読み、項目やタスクを足すエージェント。
- 別の PC `#同期`: 同じ Markdown フォルダを共有する、もう一台のジャーナルサーバー。

- 今日を書き始める #利用者

  - アプリを開く
    - 今日のジャーナルが空の項目1つで開く
      - フッターにサーバーとの接続状態が出る
        - vv ホームリンクがあればそのページが開く
  - 項目を書く
    - 入力した文はすぐ表示され、一息置いて自動保存される
      - v 日本語入力中（IME）のキーは項目の操作にならない
        - ^ 開いたままのコードフェンスは保存時に閉じられる
    - Enter で項目を分け、途中の文は下の新しい項目へ移る
      - Shift+Enter で項目の中で改行する
        - ^ 行頭の Backspace で上の項目につなぎ、行末の Delete で下の項目をつなぐ
          - ^ 素早い Enter や Tab は、次のエディタができるまで保留して取りこぼさない
  - 構造を整える
    - Tab で子ごと1段深く、Shift+Tab で1段浅くする
      - Alt+Shift+↑↓ で子ごと兄弟を越えて動かす
        - ^ Ctrl+↑ で子を隠し、Ctrl+↓ で見せる（Mac では Cmd+↑↓）
          - vv 論理アウトデントでは親の最後の子の後ろへ動き、親子関係が壊れない
  - 取り消す
    - v Ctrl+Z で元に戻し、Ctrl+Shift+Z でやり直す
      - ^ 短い間隔の入力は1つの取り消し単位にまとまる
        - ^ 作成・削除・移動・折りたたみもサーバーごと戻る
- 日々をたどる #利用者

  - タスクにする
    - v Ctrl+Enter で 通常 → タスク → 進行中 → 完了 と切り替わる
      - ^ チェックボックスが本文の前に出る
        - ^ 日次ジャーナルでタスクにすると、その日の日付が plan になる
          - 開始・終了の時刻が項目に表示される
  - 日を移る
    - v 前日・翌日のボタンで隣の日へ行く
      - ^ 下へスクロールすると前の日が続けて読み込まれる
        - カレンダーから日付を選んで開く
          - ^ 週のジャーナルを前週・次週へ移る（ISO 週か US 週かは設定）
            - ^ 月・年のジャーナルも開ける
  - 項目を別の日へ送る
    - v 先頭の項目を上へ動かすと翌日の末尾へ移り、翌日が開く
      - ^ 末尾の項目を下へ動かすと前日の先頭へ移る
        - ^ 移動元が空になるときは空の項目が残る
          - 日の先頭の項目は Backspace で前の日につながらない
  - 片付ける
    - vv Send to Stash で項目を子ごとページ末尾の「# Stash」見出しの下へ移す
- まとめて扱う #利用者

  - 複数の項目を選ぶ

      - ^ 本文の外へマウスをドラッグすると項目の選択になり、端で自動スクロールする
        - ^ 親を越えて広げると部分木ごと選ばれる
          - ^ Escape で何も変えずに選択をやめる
  - 選んだ項目を動かす
    - vv Delete で消す（ページが空になるなら空の項目を1つ残す）
      - ^ Tab・Shift+Tab・Alt+Shift+↑↓ でまとめて動かす
        - ^ Ctrl+C・Ctrl+X で Markdown としてクリップボードに載せる
          - ^ トランスクルージョンを含む削除・切り取りは断られる
  - 貼り付ける
    - vv 複数の段落は段落ごとの項目になる
      - ^ Markdown のリストは入れ子を保って項目になる
        - ^ このアプリからコピーした文は階層を保って戻る
          - ^ Shift を押しながら貼ると、分けずにそのまま1項目に入る
            - ^ 画像はアップロードされ、カーソル位置にリンクされる
              - ^ 画像のファイルをドロップすると、落とした位置にリンクされる

  - ページを作る

      - ^ ヘッダーの新規ページボタンで作る

    - vv サイドバーの index 一覧から開く（名前順・更新順・公開順、フォルダが先）

        - ^ 検索で項目とページ名を探し、キーボードで選んで項目まで飛ぶ
          - ^ 本文のウィキリンクをクリックして開く（Ctrl で新しいタブ、Shift で新しいウィンドウ）
            - ^ 編集中は Ctrl+O でカーソル位置のリンクを開く
              - ^ バックリンクで、このページを指す項目をリンク元ごとに見る
    - vv Home・ルート・タグのボタンで戻る
  - ページを直す
    - vv タイトルとフォルダを書き換える（同名があれば上書きを確認）
      - ^ 子のない index ページをフォルダ名のページに降格する
        - ^ ページを確認してから削除する
          - ^ サイドバーの右クリックで Markdown ファイルのフォルダを開く
  - プロパティを付ける
    - vv タイトルの下の行で `+` と `×` で足し引きする
      - ^ tags は `#` を外し、重複をまとめる。追加されたタグは拡張にも伝わる
        - ^ created・modified は消せず、published があると一覧に印が付く
          - ^ 使えるキーと型は設定で定義する
  - 項目をつなぐ
    - vv `[[` と打つとページ名の候補が出て、Enter で補完される
      - ^ `#タグ` はサーバーが tags プロパティにし、タグページにまとまる
        - ^ Copy Reference と Paste as Transclusion で、他ページの項目をその場に写す
          - ^ 写した項目は参照元で編集・分割・移動され、Remove Transclusion で元に戻る
  - 本文を読む
    - 見出し・リスト・コード・表・タスクリスト・脚注・画像・アラートが Markdown として描かれる
      - コードは言語ごとに色分けされる
        - Shift+ホイールで項目ごとの文字の大きさを変え、Reset Zoom で戻す
          - ^ サイドバーの Contents に見出しの目次が出る

  - アトラスを開く

      - ^ フォルダは最後に見た形（マップか一覧か）で開く
        - ^ 上へボタンで1つ上のフォルダのアトラスへ行く

  - カードを置く
    - vvv 未配置の一覧からキャンバスへドラッグして置く
      - ^ 保存が断られるとカードは元の場所に戻り、理由が出る
        - ^ カードのアイコンはページのタグから決まり、公開済みのページは分かる
    - vvv ドラッグで動かし、Ctrl+ホイールで大きさを変える（半分より小さくならない）
    - vvv 右クリックの Remove from Atlas で未配置に戻す
    - vvv 右クリックの Delete Card でリンクカードやノーマルカードを項目ごと消す
    - vvv 右クリックの Edit で項目の本文を Markdown のまま書き換える
    - vvv Edit のダイアログで複数行を書き、Preview で描いた形を見る
    - vvv Edit のダイアログで `[[` と打ち、ページ名の候補からリンクを書く
    - vvv 何もない所の右クリックの Add Card で、書いた本文のカードを作る
  - まとまりを作る
    - vvv Ctrl を押しながらカードの上に落とすとグループになり、同じ色が付く
    - vvv グループの縁にタイトルを書く（どの辺に沿わせるかを選ぶ）
    - vvv グループの外へドラッグすると抜ける
  - 書き込む
    - vvv 空いた場所の右クリックで吹き出しを置き、文と向きを書く

  - 設定を変える
    - vvvv Markdown の作業フォルダを選ぶ（反映にはサーバーの再起動が要る）
      - ^ 週番号の方式、論理アウトデント、タグフォルダ、ホームリンクを決める
        - ^ プロパティ定義を足し、断られた理由を読む
  - サーバーの変化を受け取る
    - v 接続が切れたら間隔を広げながらつなぎ直し、状態がフッターに出る
      - 別の場所でページが変わると、サイドバーとバックリンクが更新される
        - ^ 開いているページのファイルが変わると、編集が終わってから読み直される
  - 別の PC と同じフォルダを使う
    - vvvv 書いたページは数秒後に Markdown ファイルになり、相手の PC に取り込まれる

  - 拡張機能から項目を作る
    - vvvv サーバーで動く拡張が、ページ作成やタグ追加を受けて項目を作る
      - ^ テンプレートの項目は、唯一の空の1行目を上書きし、他の項目をトランスクルードできる
        - ^ 拡張はサーバーからクライアントに確認を求める
  - 外部アプリから使う
    - vvvv URL スキームでデスクトップアプリ（付箋）を起動する
      - ^ Web アプリ（todo）がサーバーの API でタスクを読み書きする
  - AI エージェントが使う
    - vvvv MCP でページを探し、項目を読み、項目やタスク（due・cancelled）を足す

スライスのゴールは、次のとおりである。ウォーキングスケルトンは、今日のジャーナルに書き、整え、読める。毎日の記録は、タスク・日の移動・取り消しがそろう。知識の整理は、ページ・リンク・検索・まとめて扱う。地図は、アトラスで俯瞰する。連携は、設定・同期・拡張・AI である。

スライスは、新しい利用者がこのプロダクトを使い込んでいく順であり、また一から作り直すときの Walking Skeleton からの積み上げの順でもある。2026-11-02 時点で、すべてのカードは実装済みである。

## まだ決めていないこと

- 月・年のジャーナルは開けるが、週以外の前後移動はない。要るかどうか。
- due と cancelled は MCP が付けるだけで、画面に出す処理がない。
- アトラスの大きなフォルダ（カードが数百枚）での使い心地は確かめていない。
