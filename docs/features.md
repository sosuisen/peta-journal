# features

アプリとサーバーのテストを要約した、ユーザー目線の機能の一覧である。アプリ（シェル）の節には、UIの操作と入出力を書く。サーバーの節には、APIを書く。内部の仕組みは書かない。

アプリの節は、`storymap.md`のアクティビティとタスクに沿って分ける。付箋紙の節は、`storymap-stickies.md`に沿って分ける。

2026-11-27時点のテストから作った。

## Web版

### 今日を書き始める

#### アプリを開く

- アプリを開くと、今日のジャーナルが開く
  - 新しい日のジャーナルには、空の項目が1つある
- 画面の読み込み中も、ヘッダー・サイドバー・本文・フッターの枠が出る
  - 読み込み中のフッターは、接続状態を「connecting」と出す
  - 画面の部品が読み込めないと、その枠に描けなかったことが出る。ほかの枠は出たままである
- ヘッダーのボタンで移る
  - Root・Tags・Today・Home のボタンで、それぞれのページが開く
  - Ctrl+Alt+Enter でホームが開く。Shift・Command を加えたときと、日本語の変換中は開かない
- フッターに、サーバーとの接続状態と、フォーカスした項目の ID が出る

#### 項目を書く

- 打った文はすぐ表示され、サーバーに保存される
  - 日本語入力の変換中のキーは、項目の操作にならない
  - 素早く打ったキーは、次のエディタができるまで取っておかれ、取りこぼされない
  - 編集欄は、本文の高さに伸びる
  - 編集欄の見出しの行は、段に合った大きさの太字になる
- 表示中の項目の文字をクリックすると、その文字の位置にカーソルが入る
  - 太字やリンクの記号、リストの印は飛ばして数える
  - リンクをクリックしたときは、編集にならずリンクが開く
- Enter で項目を分け、カーソルより後ろの文は下の新しい項目へ移る
  - Enter の直後に打った文と Tab は、新しい項目に入る
  - 続けて素早く押した Enter も、1回ずつ項目を作る
- Shift+Enter で、項目を分けずに改行する
  - Ctrl+Shift+Enter や、Shift とほかのキーは改行にならない
- 行頭の Backspace で上の項目につなぎ、行末の Delete で下の項目をつなぐ
  - 直前に打った文も、つないだ項目に残る
  - つないだ直後に打った文は、2つの文の継ぎ目に入る
- 開いたままのブロックは閉じられる
  - ```` ``` ```` と打つとコードフェンスが閉じ、中の Enter は行を足す
  - `>>>` のような、ほかのブロックの開きも閉じられる
- 項目のメニューは、項目のボタンの下に開く
  - メニューの外のクリックと Escape で閉じる。中のクリックでは閉じない
  - Copy で本文をコピーし、Cut で本文をコピーしてから空にする
- ページの項目をすべて消しても、空の項目が1つ残る

#### 構造を整える

- Tab で子ごと1段深く、Shift+Tab で1段浅くする
  - 先頭の項目は深くできず、一番上の段の項目は浅くできない
- Alt+Shift+↓ で子ごと次の兄弟の下へ、Alt+Shift+↑ で前の兄弟の上へ動かす
  - 間を置かずに続けて押した移動も、順にすべて行われる
  - 移動の直後に打った文は、動かした項目に入る
- 論理アウトデントでは、Shift+Tab で子ごと1段浅くし、兄弟たちの後ろへ動かす
- Ctrl+↑ で子を隠し、Ctrl+↓ で見せる（Mac では Cmd+↑↓）
  - 子のある項目には三角が出て、押すと開け閉めする。閉じた項目は印が変わる

#### 取り消す

- Ctrl+Z で元に戻し、Ctrl+Shift+Z でやり直す
  - 分割・結合・字下げ・移動・論理アウトデント・タスクの切り替え・削除を戻せる
  - 戻した結果はサーバーにも残り、読み込み直しても戻ったままである
  - 削除した項目は、折りたたみやタスクの状態ごと戻る
  - 選択も編集もないときの Ctrl+Z でも、直前の削除が戻る

### 日々をたどる

#### タスクにする

- Ctrl+Enter で、通常 → タスク → 進行中 → 完了 → 通常 と切り替わる
  - タスクには、本文の前にチェックボックスが出る。進行中は中間の印、完了はチェックになる
  - チェックボックスを押すと、次の状態に進む
  - 日のジャーナルでタスクにすると、その日の日付が予定日になる
  - 完了から通常に戻したあと Ctrl+Z で戻すと、開始と終了の時刻も戻る
- タスクの時刻が項目に出る
  - 進行中のタスクは、始めた時刻を「09:05-」の形で出す
  - 完了したタスクは、かかった時間を「1h5m」「5m」「30s」の形で出し、時刻はツールチップに出る
  - 終わりが始めより前のときと、時刻が読めないときは「0s」になる

#### 日を移る

- 日と週のジャーナルには、前と次へのボタンがある。月と年のジャーナルにはない
  - 前日のボタンで前の日が開く
- 下へスクロールすると、前の日が続けて読み込まれ、日の境でも跳ばずに一定の速さで進む
  - 下へスクロールしたジャーナルは、見出しに印が付く
- サイドバーのカレンダー
  - 今日の月が出て、今日に印が付く。他の月の日にも印が付く
  - 週の番号が各週の前に出る。1桁の番号は0を付けて2桁で出る
  - `<` と `>` で前の月・次の月へ移る
  - 日・週の番号・月の名前・年を押すと、そのジャーナルが開く
  - Ctrl で新しいタブ、Shift で新しいウィンドウに開く
- ジャーナルの見出しのカレンダー
  - 日付かカレンダーのボタンを押すと、見出しの下に今日の月で開き、もう一度押すと閉じる
  - 表示中のジャーナルの日が、選んだ日として印が付く
  - そこからジャーナルを開くと閉じる。新しいタブやウィンドウに開いたときは開いたままである
- 検索欄に「today」と打つと（大文字小文字を問わない）、候補の一番上に Open Today が出て、選ぶと今日のジャーナルが開く

#### 項目を別の日へ送る

- 日の先頭の項目を Alt+Shift+↑ で上へ動かすと、翌日の末尾へ移り、翌日が開く
  - 直前に打った文も一緒に移る
  - 移動元の日には空の項目が残る
  - 移した項目の編集が続く

#### 片付ける

- 項目のメニューの Send to Stash で、項目を子ごとページ末尾の「# Stash」見出しの下へ移す

### まとめて扱う

#### 複数の項目を選ぶ

- エディタから Shift+↑↓ で、上下の項目へ選択を広げる
  - 親から始めた選択は子ごと選ばれ、さらに先へ広がる
  - Escape で、何も変えずに選択をやめる
- 項目の文字からドラッグすると、押した文字からマウスの下の文字までが選ばれる
  - 項目をまたいで項目の選択になると、文字は選ばれない
  - 項目を選ぶドラッグでマウスを上下の端に置くと、一定の幅で少しずつスクロールする
  - 端から離れるとスクロールは止まり、端に戻ると再び始まる。一番上より上には行かない

#### 選んだ項目を動かす

- Delete で選んだ項目を消す
  - 折りたたんだ親は、隠れた子ごと消える
  - すべての項目を消すと空の項目が1つ残り、続けて打った文はそこに入る
- Ctrl+C で選んだ項目をクリップボードに載せ、貼ると階層を保って戻る
- 他のページが写している項目を消すときは、確認のダイアログが出る
  - ダイアログは Cancel にフォーカスがあり、Enter だけでは消えない
  - Cancel と Escape で、項目と選択はそのまま残る。OK で消える
  - 写されていない項目は、確認なしで消える
- トランスクルージョンを選んで Delete・Backspace・Ctrl+X すると、写した項目だけが消え、元の項目は残る

#### 貼り付ける

- 複数の段落を貼ると、段落ごとの項目になる
- Markdown のリストを貼ると、入れ子を保って項目になる
- Ctrl+Shift+V で貼ると、分けずにそのまま1項目に入る
  - Shift を放すか編集欄を離れると、ふつうの貼り付けに戻る
- 画像を貼ると、アップロードされてカーソル位置にリンクが入る
  - Ctrl+Z で、入れたリンクを取り消せる
- 画像のファイルを編集欄にドロップすると、落とした位置にリンクが入る
  - 表示中の項目にドロップすると、本文の末尾に入る
  - 項目の外に落としたファイルは、ブラウザで開かれない
- 項目のメニューの Cut・Copy で、1つの項目の本文をクリップボードに載せる

### ページで知識を整える

#### ページを作る

- ヘッダーの `+` ボタンで新しいページを作る。検索欄に文字があれば、それが名前の候補になる
- 検索の候補の Create で、打った名前のページを作る

#### ページを開く

- サイドバーの index 一覧から開く
  - 見出しはフォルダの名前で、押すとそのフォルダの index が開く
  - 上のフォルダ（`../`）とページが並び、開いているページに印が付く
  - Sort のメニューで、名前・更新日時・公開日時の昇順と降順の6つから並べ方を選ぶ。今の並べ方に ✓ が付く
  - 並べ方は、フォルダごとに次に開いたときも残る
- サイドバーの Recent Pages から開く
  - フォルダ・公開したページ・ふつうのページで、アイコンが違う。フォルダの名前は、ページ名の前に出る
- 検索で項目とページ名を探す
  - Ctrl+/ でどこからでも検索欄に移る。編集中でも入力欄の中でもなければ、`/` だけでも移る
  - 候補には、ページ・項目・Today・Create がある。項目は、ページ名と、一致した所に印の付いた抜き書きを出す
  - ↑↓ で候補を選び、Enter で開く
  - 答えが来る前に押した ↓ と Enter も、新しい問い合わせの最初の候補を開く
  - 候補をクリックしても開く
- 本文のウィキリンクをクリックして開く
  - Ctrl+クリック（Mac では Cmd+クリック）と中ボタンのクリックで、新しいタブに開く。Shift+クリックで新しいウィンドウに開く
  - 名前に `#`・`%`・空白・日本語を含むページへのリンクも開く。右クリックでコピーするリンクも、そのページの URL である
- 編集中は Ctrl+O で、カーソル位置のウィキリンクやタグのページを開く
- バックリンクで、このページを指すページと項目を見て、押すと開く
  - Shift・Ctrl・Command を押したクリックは、ブラウザが新しいタブやウィンドウで開く
  - リンクがなければ、バックリンクの欄は出ない
- 見出しのパンくずで、上のフォルダの index を開く
  - 一番上のフォルダのページには、パンくずが出ない
  - 一番上の index は、`(root)/` と出る
- サイドバーの一覧は、読み込み中にそう表示され、失敗するとそう表示される。1つの一覧が出せなくても、ほかは出る

#### ページを直す

- 見出しを押すと、フォルダとページ名の欄になる
  - 押した位置のページ名にカーソルが入る
  - Enter か、欄の外にフォーカスを移すと保存する。フォルダの欄とページ名の欄の間の移動では保存しない
  - Escape で、何も保存せずに戻る
  - 日本語の変換を確定する Enter では保存しない
  - 一番上のフォルダのページには、フォルダの欄がない
  - index では、最後のフォルダを押すとフォルダ名の編集になり、ページ名は変えられない
- index の見出しには、名前を変えられるときだけ降格のボタンが出る
  - 押して確認すると、そのフォルダのアトラスが消え、index がフォルダ名のページになる
- ページのメニューの Delete page で、確認してからページを消し、今日のジャーナルが開く
  - メニューはもう一度押すと閉じる
- 文書のページのメニューから、プロパティの編集を開ける。ジャーナルと、開けなかったページにはない
- サイドバーのページを右クリックすると、そのページのファイルのフォルダを開くメニューが出る
  - 外のクリックと Escape で閉じる

#### プロパティを付ける

- プロパティは、見せるときだけタイトルの下に出る。足しかけの行があれば、閉じても残る
- 1行に名前と値が出る。消せるものにだけ `×` があり、押すと消える
- 値の入力欄は型に合う
  - 数・日付は専用の入力欄、一覧は「a, b」、範囲は「x, y, width, height」の形の文字の欄になる
  - 文字の値は、変えたときに保存する
  - チェックは、押すたびに保存する
  - 日時は分までの時刻で出る。変えて欄を離れるか Enter で保存する
  - 変えられない日時は、読むだけの欄に出る
- タグの一覧
  - タグはそのページへのリンクで、押すとアプリの中で開く。キーを押しながらだと、新しいタブかウィンドウで開く
  - タグの `×` で、そのタグを消す
  - `+` で入力欄が開き、Enter か欄を離れると打ったタグを足す。空白だけなら何も足さない。Escape で足さずに閉じる
  - タグをドラッグして並べ替える。他のタグの右半分に落とすと後ろへ、真ん中か左半分なら前へ動く
  - ドラッグ中は、引いたタグと落とす側に印が付く。ほかから引いてきた文字は、タグの上に落とせない
- 新しい行
  - `+` で、まだないキーを選ぶ行を足す
  - キーを選ぶと型に合う入力欄に移り、値を入れて Enter か欄を離れるとプロパティになる
  - 日時の行は今の時刻で始まり、Enter だけでその時刻になる
  - 一覧のキーを選ぶと、タグの入力欄が開く
  - 行の `×` で、保存せずに行を消す。キーを選ぶ前の行は保存されない
  - 新しい行はいくつでも足せる

#### 項目をつなぐ

- `[[` と打つと、カーソルの下にページ名の候補が出る
  - 選んだ候補に印が付き、Enter か押すと補完される
  - 閉じの `]]` を打つと、自動で入った `]]` の上を進む
- 表示中の項目の `#タグ` は、タグのページへのリンクになる
- コピーした HTML では、ウィキリンクとハッシュタグがアプリの URL のリンクになり、貼った先から開ける
- 項目のメニューの Copy Reference のあと、別の項目で Paste as Transclusion を選ぶと、その項目が元の項目と子を写す
- トランスクルージョンを編集する
  - 写した項目に打った文と貼った項目は、元のページに入る
  - 写した項目の途中で Enter を押すと、元の項目が分かれ、後ろの文は元のページに残る。写す側のページへは移らない
  - 子を見せている写しでは、分けた後ろの文が最初の子として出て、続けて編集できる
  - 写した項目の先頭や末尾の Enter では、写す側のページに空の項目ができる
  - 写した子を Alt+Shift+↑↓ で動かすと、元のページで動き、Ctrl+Z で戻る
  - 分割も Ctrl+Z で戻せる
- 項目のメニューの Remove Transclusion で、項目が空になり写さなくなる。元のページは変わらない
  - トランスクルージョンでない項目のメニューには出ない
- 他のページが写している項目を Backspace や Delete でつなぐときは、確認のダイアログが出る
  - Cancel と Escape では、項目とカーソルの位置がそのまま残る。OK でつながる
- 元の項目が見つからない写しは、本文の代わりにそのことを出す
- 写しの項目の印は四角になる

#### 本文を読む

- 本文は Markdown として描かれる
  - 言語を書いたコードブロックは色分けされ、言語の札が出る。言語を書かないものは、そのままである
  - 画像の URL の `w` と `h` が、表示する画像の幅と高さになる
  - assets フォルダの画像は、どのフォルダのページでも表示される
  - 隠し文字（スポイラー）は、文字の色が背景と同じで読めない
  - 脚注の参照を押すと、脚注が画面の中ほどに出る
- Shift+ホイールで項目ごとの文字の大きさを変える。上に回すと大きくなる
  - 大きさを変えた項目のメニューにだけ Reset Zoom が出て、押すと戻る
- サイドバーの Contents に、見出しが段の印付きで並び、押すとその項目へスクロールする
  - 見出しがなければ、Contents は出ない

### 地図で俯瞰する

#### アトラスを開く

- index の見出しのマップボタンで、そのフォルダのアトラスが開く。一番上の index にもある
  - アトラスでは、同じボタンが押された形になり、押すと index に戻る。見出しはフォルダの名前になる
  - 文書のページには、マップボタンがない
- アトラスは、そのフォルダで前に見た位置と倍率で開く
  - 前の位置が読めなければ、真ん中から始まる
- 上へボタンは1つ上のフォルダの名前を出し、押すとそのアトラスへ行く。一番上のフォルダにはない
- カードのラベルを押すと、そのページが開く。Ctrl でタブ、Shift でウィンドウに開く

#### カードを置く

- 置いていないカードは、キャンバスの横の一覧に出る。フォルダには印が付く
  - 一覧の名前を押すと、そのページが開く
- 一覧のカードをキャンバスへドラッグして置く
  - つかんだ位置のまま置かれる
  - ほかから引いてきた文字は、落としても何も起きない
- カードを右クリックすると、その場所にメニューが出る
  - Remove from Atlas で、カードを置いていない一覧に戻す
  - 外のクリックと Escape で、何もせずに閉じる
  - キャンバスでは、ブラウザの右クリックメニューは出ない

#### まとまりを作る

- 一覧のカードをキャンバスの上で引くと、Ctrl（Mac では Command）を押している間、入るグループに印が付く
  - Ctrl を押して落とすと、そのグループに入る。Ctrl なしで落とすと、カードの上でもグループには入らない
  - キャンバスから離れると、グループの印が消える

### 設定とサーバーと付き合う

#### 設定を変える

- サイドバーの下の設定ボタンで、設定の画面が開く
- Markdown のフォルダは読むだけの欄に出て、Browse... でフォルダを選ぶ
- 週番号の数え方を選び、論理アウトデントを切り替える
- タグのフォルダとホームを書き換える。1文字ごとでなく、変え終えたときに反映される
- プロパティの定義
  - 定義ごとに、名前・型・ページに使えるかが1行に出る。システムのキーには印が付き、消せない
  - Delete を押すとその場で確認が出て、No でやめ、Yes で消す
  - 名前と型を選んで Add で新しいキーを足す。名前の前後の空白は除かれる
  - 足せたときは名前の欄が空になり、断られたときは残る
  - 定義の誤りは、画面に出る

#### サーバーの変化を受け取る

- ほかのクライアントや端末が変えた項目は、編集中でも画面に出る
  - ほかのクライアントが消した項目は、編集を終えなくても消える
  - ほかの項目の文の変更は、編集中でも出る。同期のツールがファイルを書き換えたときも同じである
  - 編集中の項目の文が変わったときは、こちらで打っていなければ、エディタにその文が出て続けて打てる
  - こちらで打っていれば、打った文が残り、保存で上書きする
- ほかのクライアントが最後の項目を消したあと Ctrl+Z で戻しても、ページには空の項目が1つ残る

#### 画面の枠を整える

- ヘッダーの ☰ ボタンで、サイドバーを閉じたり開いたりする
- サイドバーの縁のつまみを引くと、幅が200pxから600pxの間で変わる。幅は次に開いたときも残る
  - 初めは260pxである。閉じたサイドバーにはつまみがない
- サイドバーの節は、それぞれ見出しで閉じたり開いたりする。閉じた節は、次に開いたときも閉じている
- 下へスクロールしたページは、見出しに印が付く

## Emacs版

### 今日を書き始める

- アプリを開く
  - 起動すると、今日のジャーナルが開く
  - 今日のジャーナルを開いたまま日付が変わると、新しい日のジャーナルが開く
    - Emacsのフレームにフォーカスが戻ると、すぐに日付を確かめる。スリープから戻ったときなどである
  - 1つのバッファに、ページ全体が表示される。別のページが開くと、カーソルは先頭の項目へ移る
- キーの決まり
  - 書きながら押すキーは`C-c C-文字`、ページ全体の操作は`C-c C-x`のあとの1文字である
  - 項目は`M-S-矢印`で動かし、字下げする。`M-矢印`は、Emacsの単語の移動などに残る
  - `C-c C-c`は、Emacsでは「確定」の意味なので空けてある
- 画面
  - 各項目は、バレットと本文で描かれる。字下げは、レベルの分の幅で見えるだけで、バッファの文字には入らない
  - 編集中でない空の項目には、バレットの代わりに同じ幅の空白が描かれる
  - トランスクルージョンは`⊡`、折りたたんだ項目は`◉`、折りたたんだトランスクルージョンは`▣`のバレットで示される。行末には何も足さない
  - ジャーナルの日付は、項目の上の編集できない行である
  - 項目の間には、`peta-journal-item-gap`の分の隙間がある。本文の中の改行にはない
  - 複数行の本文は、次の項目の手前までが1つの項目である
  - 折り返しの行には、フリンジのマークを出さない
  - 長い本文は、バレットの行から始まる。空白のない日本語も長いURLも、バレットだけの行を作らない
    - 本文の途中に空白があっても、日本語はその行に続く
    - バレットの後ろの空白は、強調されずに普通の空白に見える
  - 他からの変更で行が書き換わっても、カーソルは同じ項目の同じ位置に留まる。項目が消えたら、同じ順番の項目へ移る
- カーソル
  - バレット、項目の区切り、日付の行には留まらず、進む向きの項目の本文へ移る
  - 先頭の項目の先頭と、最後の項目の末尾では、そこに留まる
  - バレットと項目の間の区切りは編集できない。項目をまたいで消すと、エラーになる
- 項目を書く
  - 打った文字は保存される。`C-x C-s`で編集を終えるとすぐに保存され、次のコマンドで編集がまた始まる
  - 一息つくと、どのバッファでも編集が閉じる
  - 空の項目にも、本文の先頭と末尾にも打てる。打った文字は、バレットやタスクの記号の色を受け継がない
  - 本文の中の改行の続きの行にも、その項目の字下げが付く
  - `[[`を打つと`]]`が補われ、続けて打った文字はその間に入る。`]]`まで手で打っても`]`は増えず、カーソルはリンクの後ろへ進む
  - ```` ``` ````を打つと、閉じるフェンスが補われる。`>>>`のようなほかのブロックや、`<!--`も同じである
- 構造を整える
  - Enterで項目が分かれ、カーソルは新しい項目の先頭へ移る。続けて打った文字は新しい項目に入る
    - 閉じていないコードフェンスの中のEnterは、項目を分けずに改行を入れる。閉じたフェンスの後ろでは、ふつうに分ける
  - 本文の先頭のBackspaceで上の項目に、末尾の`C-d`で下の項目がつながる。途中では文字を消す
    - つなぐ直前に打った文字も保存される
  - `TAB`と`M-S-<right>`で字下げし、`<backtab>`と`M-S-<left>`で戻す。先頭の項目は字下げできない
  - `M-S-<up>`と`M-S-<down>`で、項目を上下へ動かす
  - `C-c C-f`で折りたたむと、子の行が隠れ、バレットが変わる
  - `C-c C-d`は、項目を子ごと消す
    - 行は、サーバーの答えのあとで消える
    - 他から参照される項目では、確認を尋ねる。断っても、サーバーが断っても、何も消えず、その項目の編集は続く
- 取り消す
  - `C-/`で、打った文字や項目の分割を、操作の順に取り消す
  - 取り消した操作は、やり直せる

### 日々をたどる

- タスクにする
  - `C-c C-t`で、項目がタスクになり、状態が変わる
  - タスクにもバレットがあり、状態の記号（`☐` `⊟` `☑`）はその後ろに付く。タスクのバレットも、折りたたみとトランスクルージョンを示す
    - 実行中の記号は、大きく表示する。大きさは`peta-journal-running`のfaceで変えられる
  - カーソルは、タスクの記号の上に留まらない。本文はその後ろから始まる
- 日を移る
  - `C-c C-n`で次の日の、`C-c C-p`で前の日のジャーナルへ移る。`C-c C-j`で今日のジャーナルへ戻る
  - `C-c C-x c`でEmacsのカレンダーが開く。日で`RET`を押すと、その日のジャーナルが開き、カレンダーは閉じる
    - `w`、`m`、`y`で、その日の週、月、年のページが開く。週の数え方は、サーバーの設定に従う
    - カレンダーを開くと、これらのキーと閉じるキーの案内がエコーエリアに出る
    - 開く前に、編集中の項目の編集を終える。日のないところでは、何も開かず、そのことを伝える
    - ふつうに開いたカレンダーには、これらのキーは付かない
- 片付ける
  - `C-c C-x S`で、項目を子ごと、ページの最後の`# Stash`の見出しの下へ送る。見出しがなければ作られる
    - まだ保存していない打った文字も、一緒に送られる
    - 行は、サーバーの答えのあとで動く

### まとめて扱う

- 複数の項目を選ぶ
  - `C-c SPC`で、今の項目の編集を終え、その項目を子ごと選ぶ
  - 選ばれた行には選択の色が付き、バッファは書けなくなる。選択が終わると、元に戻る
  - 選択の間、カーソルが動いても、項目の編集は始まらない
  - `n`、`C-n`、`<down>`、`S-<down>`で下へ、`p`、`C-p`、`<up>`、`S-<up>`で上へ選択を伸ばす
  - `C-g`、`q`、`<escape>`で選択を終える
- 選んだ項目を動かす
  - `M-S-<up>`と`M-S-<down>`で、選んだ項目がまとめて動く
  - `TAB`と`M-S-<right>`で字下げし、`<backtab>`と`M-S-<left>`で戻す
  - `d`、`DEL`、`C-d`、`<delete>`で、選んだ項目がまとめて消え、選択は終わる
  - `w`と`M-w`でコピーすると、選んだ項目のMarkdown（`- a\n- b`）がkill ringに入る。`C-w`で切り取る
  - `C-/`で取り消し、`C-?`でやり直す
- 貼り付ける
  - `C-y`は、kill ringの先頭の文字を、項目の貼り付けとして入れる。文字の属性は持ち込まない
  - クリップボードに画像だけがあるとき、`C-y`はその画像を挿入する
    - 画像は`image.png`という名前でサーバーの`assets`フォルダに送られ、カーソル位置にリンクが入る
    - クリップボードに文字もあるときは、画像があっても、文字を貼り付ける
  - `C-c C-x i`で選んだ画像ファイルは、サーバーの`assets`フォルダに送られ、カーソル位置にリンクが入る
    - リンクの文字は元のファイル名で、リンク先はサーバーが付けた名前である
    - 候補には、画像とフォルダだけが出る。拡張子の大文字小文字は問わない
    - 画像でないファイルは断る。項目の外では、ファイルを尋ねる前に断る
    - リンクが入るまで、打ったキーは待たされ、リンクの後ろに入る
    - 読めないファイルや送信の失敗は、理由を表示する。本文は変わらない
- トランスクルージョン
  - `C-c C-x w`は、項目の参照をkill ringに入れる
  - `C-c C-x t`は、kill ringの先頭の参照の項目を、今の項目のトランスクルージョンにする。項目は元の項目の本文を見せる
    - Web版の「Copy Reference」の参照も、クリップボードを通して使える
    - 参照に見えない文字では、何も起きない。kill ringが空なら、断る
  - `C-c C-x T`は、トランスクルージョンをふつうの項目に戻す。切れたものも戻せる。ふつうの項目では、尋ねずに断る

### ページで知識を整える

- 本文を読む
  - カーソルのない行は、表示の形で描かれる。Markdownの記号は見えず、太字や見出しなどに色が付く
    - 表示の形の文字は編集できない
    - 見出しは深さ1から6ごとに、リスト、引用、区切り線、コードブロックは、それぞれの見た目で描かれる
    - リストや引用の中のコードブロックも、記号や引用の印の後ろにそろう
    - 表の升は、全角を2と数えた幅で列ごとにそろい、縦線で区切られる
  - カーソルのある行は、本文のMarkdownを色なしで見せる
    - 表示の形の行に入ると、カーソルはMarkdownの中の同じ文字の位置に置かれる
    - カーソルが出ると、その行は表示の形に戻る。そこで打った文字も、表示の形で見える
- 画像を見る
  - 表示の形の行では、`assets`の画像が、代わりの文字の場所に見える。前後の文字と行の区切りはそのまま見える。Webの画像はリンクになる
  - カーソルのある行は、画像を見せずにMarkdownを見せる。カーソルを動かすと入れ替わる
  - 画像が届くまでは、代わりの文字が見える。代わりの文字のない画像は、`image`の文字で見える
  - リンクの`#w=`と`#h=`の大きさで見える。片方だけなら、その向きだけが決まる
  - 大きさの指定がなくても、画像はウィンドウに収まる。字下げの分を除き、ウィンドウの大きさが変わると合わせ直す
  - 取得できない画像、読めない形式、画像を出せない環境では、代わりの文字のままで、エラーにならない
    - 取得できなかった画像は、別のページを開くともう一度取得する
  - 画像の中身は、上限（`peta-journal-image-memory-limit`）までメモリに残す。超えると、開いたページにない画像を、使ってから長いものから忘れる
- ページを開く
  - `C-c C-o`で、カーソルの位置のウィキリンクやタグのページが開く。リンクの上でなければ、そのことを伝える
  - 表示の形の行のリンクは、クリックで開く。カーソルは動かない
    - ページへのリンクは、そのページを開く。Webのリンクと`assets`のファイルは、ブラウザーで開く
  - `C-c C-b`で前のページへ戻り、`C-c C-x f`で戻る前のページへ進む。最初のページでは、戻る先がない
  - `C-c C-s`で検索窓が開き、ミニバッファに入力する。結果は下の窓に並び、入力に合わせて変わる
    - 結果はページ、新しいページの作成、項目の順に並ぶ。項目には、その後に抜粋が付く
    - 検索語が空になると、結果は消える
    - 何も入力せずに`TAB`を押すと、最近のページがその順のまま並ぶ。検索語があるときの`TAB`は、結果を変えない
    - 先頭の結果が選ばれていて、`C-n`と`C-p`で動く。端では反対の端へ回る。同じ結果がまた届いても選択は動かず、結果が変わると先頭へ戻る
    - `RET`で選んだ結果を開き、窓は閉じる。検索語の新しいページも、ここから作れる
    - `C-n`、`C-p`、`RET`は、入力した語の結果が届くのを待ってから動く。入力の直後に押しても、古い結果は開かない
    - `C-g`で閉じると、どこへも移らず、結果の窓も消える
  - `C-c C-x n`で、ページを新しいバッファに開ける。別々のページを同時に編集できる
    - 名前の候補は最近のページで、名前順に並べ替えず、その順に並ぶ
    - 名前の`#`や空白も、ページ名のまま開く
    - そのページを表示中のバッファがあれば、そこへ移る
    - 別のキーで、別のバッファが表示中のページへ移ると、一度だけ警告が出る。片方の保存はもう片方に表示されない
    - 片方のバッファを閉じても、もう片方は編集できる
    - 検索は、検索を始めたバッファのページだけを移す
  - サイドバー
    - `C-c C-x s`で、フレームの左端の窓に開き、もう一度押すと閉じる
    - Webと同じ順に、今のページのフォルダの一覧、見出し（Contents）、最近のページ（Recent Pages）を並べる
      - フォルダの一覧には、見出しのindexページと`../`の親フォルダが付く。ページも親もない一覧は出さない
      - 今のページには、フォルダの一覧で印の色が付く
      - 見出しは、段の深さだけ字下げする。最近のページは、フォルダを前に付けて並べる
    - 行で`RET`を押すかクリックすると、そのページが開く。見出しの行では、ページのその項目へカーソルが移る
    - 節の中のどの行でも`TAB`を押すと、その節は見出しだけになり、もう一度押すと開く。ほかの節は変わらない
      - 見出しの前の`▾`と`▸`のクリックでも、節を開閉する
      - 閉じた節は、どのページでも、次に起動したEmacsでも閉じている（`peta-journal-sidebar-collapsed`）
    - 開いているサイドバーは、ページの変化に合わせて描き直される
- ページを直す
  - `C-c C-x r`で、ページの名前を変える
    - 今のパスを初期値にして尋ねる。打ったばかりの文も新しい名前のページに残り、そのまま書き続けられる
    - 名前の中の`/`はフォルダの区切りである。`/`のない名前を付けると、フォルダの外へ出る
    - 同じ名前のページがあれば、上書きするかを尋ねる
    - indexページでは、フォルダのパスを尋ね、フォルダの名前が変わる
    - ジャーナル、ルートのindex、アトラスでは、尋ねずに断る
    - ページのバッファの外で`M-x`で呼んでも、そのページの名前を変える
  - `C-c C-x D`で、下にページのないindexページを、フォルダの名前のページにする
    - 付く名前を挙げて尋ね、「はい」ならそのページが開く。「いいえ」なら何も変わらない
    - 下にページのあるindexページと、indexでないページでは、尋ねずに断る
  - `C-c C-x d`で、今のページを消す
    - ページの名前を挙げて尋ね、「はい」ならページが消え、今日のジャーナルが開く。「いいえ」なら何も変わらない
  - 尋ねることが2つ続いても、1つずつ尋ねる
- プロパティを付ける
  - `C-c C-x p`で、ページのプロパティの一覧を別の窓に開き、カーソルは最初のプロパティへ移る。ページの窓でもう一度押すと閉じる
    - キーは、名前と型の見出し（`rating (number)`）で見える。全角のキーがあっても、値の列がそろう
    - 開いている一覧は、そのページの値が変わると描き直される
  - 一覧の`s`で、値を設定する
    - 変えられるキーと、ページに使えてまだ付いていないキーを、見出しで補完する。カーソルの行のキーが既定になり、今の値が初期値になる
    - キーを選ばないときと、値が空のときは、何も変わらない
    - 値は、プロパティの定義の型で保存される。今の値がリストなら、リストとして保存される
  - 一覧の`d`で、消せるプロパティを消す。カーソルの行のキーが既定になる。消せるものがなければ、尋ねずに断る
  - 設定と削除のあとも一覧は開いたままで、カーソルは同じ行に残る。`q`で閉じる
  - 日時のプロパティは、一覧でも入力でも`YYYY-MM-DD HH:MM`のローカル時刻で見える
    - まだ付いていないキーは現在時刻が初期値なので、Enterだけで今の時刻が入る
    - 初期値のままEnterを押すと、今の値のまま残り、秒を失わない
    - 日時として読めない入力は断る。ありえない日付も繰り上げずに断る
    - 日時のキーでも読めない値は、そのまま見える。直せば日時として入る
  - ジャーナルでは、尋ねずに断る
- 項目をつなぐ
  - `[[`と`]]`の間で`C-M-i`を押すと、そこに打った文字でページ名を探し、Emacsの補完で名前を入れる
    - 候補は、見つかった名前を、その順のまま示す。打った文字で始まらない名前も除かない
    - 見つかった名前が1つなら、すぐに入る。いくつもあれば、選ぶまで本文は変わらない。見つからなければ、何も変わらない
    - カーソルが名前の途中にあっても、`[[`と`]]`の間の全体が入れ替わる。カーソルは`]]`の前に残る
    - 何も打っていなければ、最近のページをその順のまま示す
    - ウィキリンクの外では、ページ名を補完しない。閉じた`]]`の後ろや、`[`が1つだけのところも外である
  - `C-c C-x b`で、このページへリンクする項目の一覧が、ページごとにまとまって開く。行を開くと、その項目の場所へ移る

### 設定とサーバーと付き合う

- サーバーの変化を受け取る
  - Markdownファイルの変更や、別のクライアントの変更は、開き直さなくてもバッファに出る
  - サーバーがいないときは、つながっていない状態になる。つながりが切れると、つなぎ直す
  - サーバーが断ったときは、その理由がEmacsに表示される
- Emacsを閉じる
  - Emacsを閉じても、打ったばかりの文字は保存される
    - サーバーが答えなければ、5秒で終わる。保存するものがなければ、すぐに終わる
  - 裏で動くプログラムが思いがけず止まると、そのバッファのモード行と警告で伝える。こちらから止めたときは伝えない

## iPhone版

### Dropboxにサインインする

- 入れたばかりのアプリは、「Sign in to Dropbox」のボタンだけを出す。検索の入力欄は出ない
  - サインインの前は、今日のジャーナルを作らない。Dropboxに同じ日のジャーナルがあるかもしれないためである
- サインインでは、Dropboxにファイルの読み書きの権限だけを求める
- サインインすると、ダウンロードの間は「Downloading」のダイアログで待たせる。終わると、ジャーナルが開き、検索の入力欄とメニューが出る
- メニューの「Sign out」でサインアウトすると、メニューは消え、ページの上に「Sign in to Dropbox」のボタンが出る
  - 取り込んだページは、そのまま読める
  - サインアウトのあとは、同期しない。次にサインインすると、Dropboxのファイルを初めから取り直す
- 同期が動いている間は、メニューにサインアウトが出ない

### Dropboxと同期する

- アプリが前に来ると同期し、「Downloading」のダイアログで待たせる。終わると、ダウンロードしたページが見える
- アプリでページを作ったり書いたりすると、少し待ってから同期し、そのページがDropboxに上がる
  - キーボードが語を変換している間は、同期は始まらない。変換が終わってから待ち、同期する
- 開いているページがダウンロードで変わると、編集中の項目の入力欄にも、ほかの端末が書いた文が出る
  - ただし、編集中の項目にこちらで打った文があれば、その文が残る
- 同期に失敗すると、吹き出しで伝え、「Try again」のボタンを出す
  - 通信できないときは「Sync failed: no connection」、ほかの理由では「Sync failed」とだけ出る
  - 「Try again」を押しても、つながらなければ同じ知らせが出る
- 失敗したあとのメニューには、「Sync」「Sign in to Dropbox」「Sign out」がある

### ページを開く

- アプリは、前に表示していたページで開く。なければ、今日のジャーナルで開く
  - サインインの前で前のページもなければ、何も開かない。最初の同期のあとに、今日のジャーナルが開く
- 検索の入力欄
  - 取り込んだページが結果に出る。選ぶと、そのページが開く
  - 入力した名前のページがなければ、「Create page」の結果が出る。選ぶと、そのページができて開く
  - 作れない名前（例: `a:b`）では、ページを作らず、訳を知らせる。知らせのボタンは「OK」だけで、押すと閉じる
  - 「today」と打つと、今日のジャーナルを開く結果が出る
- 今日のボタンは、今日のジャーナルを開く。なければ作る
  - 今日のページで下に続く過去の日付は、今日の日付と同じ大きさで出る
  - 今日のページを下までスクロールすると、前の日が読み足される
- 上端のバーの、検索の入力欄の左に、戻るボタンと進むボタンがある
  - 戻るで前のページが開き、進むで戻る前のページが開く
  - 戻る先も進む先もないときは、ボタンは出たまま押せない。起動して今日のジャーナルだけが開いているときも、そうである

### リンクに触れる

- ページへのリンクに触れると、そのページが開く
  - まだないページへのリンクでは、そのページができて開く
- タグに触れると、タグのフォルダーの下にある、そのタグのページが開く
- Webへのリンクに触れると、ブラウザで開く。開いているページは変わらない
  - `mailto:`など、http以外のリンクも、そのまま開く先に渡る
- `assets`のファイルへのリンクに触れると、アプリの中でそのファイルが開く。名前の大文字と小文字は問わない
  - ファイルがなければ、ないことを知らせる。次のリンクに触れると、知らせは消える

### 項目を装飾つきで読む

- 項目は装飾つきで出る。Markdownの記号は出ない
  - 見出しは、レベルに応じた大きさの太字になる
- コードブロックは、書かれたとおりの行で出る。表は、セルごとに出る
- `assets`の画像は、絵として出る
  - 絵の上の1行目に、代わりの文字（alt）が出る。altがなければ、ファイルのパスが出る
  - 1行目に触れると、その項目の編集になる
  - 絵に触れると、大きく開く。もう一度触れると、閉じる
  - ファイルがまだない画像は、代わりの文字だけが出る
- タスクは、状態の印を持つ。印に触れると、次の状態へ進む
- 子を隠した項目の点は、大きな薄い円の上に描かれる。子を隠していなければ、円はない

### 項目を書く

- 項目に触れると、その項目がMarkdownの入力欄になる
  - カーソルは、触れた文字のMarkdownでの位置に置かれる。文字の先頭に触れると、Markdownの先頭から書ける
  - 文字の右半分に触れると、その文字の後ろになる。行の右に触れると、行の末尾になる。絵文字も1文字として扱う
  - 文の脇に触れると、いちばん近い行の文字になる
  - 新しいジャーナルの空の項目も、触れて書ける
- 打った文字は、編集を終えた項目に出て、ページのファイルに書かれる
  - アプリが裏に回ると、保存を待っていた文字も、すぐにファイルに書かれる
- 開始記号（例: `>>>`）を打ち終えると、閉じる記号が補われる。カーソルは、その間に留まる
- Enterは、カーソルの位置で項目を分け、入力は下の新しい項目で続く
  - Enterの直後に打った文字も、新しい項目に入る。続けて打った2つのEnterも、それぞれ新しい項目を作る
- 項目の先頭でのBackspaceは、前の項目につなぐ。編集はつないだ項目で続き、カーソルはつなぎ目に置かれる
  - つなぎ目の位置では、絵文字を1文字として数える
  - 空の項目では、その項目が消え、前の項目の終わりで編集が続く
  - 先頭より後ろでのBackspaceは、前の1文字を消すだけである
  - ほかの項目が写している項目がつなぐことで消えるときは、先に尋ねる。いいえなら項目は残り、はいなら消える
- 長いページの下端の項目に触れても、キーボードが出て、編集が続く。空の項目でも同じである
- 画面を横にして、編集中の項目が見えるところから外れても、編集は続き、打った文字が入る
- 検索の入力欄で打っている間は、キーボードは検索の入力欄から離れない
- キーボードのステッカーは、文字の中の絵としては入らない。画像の貼り付けになる

### 貼り付ける

- 入力欄のメニューの「Paste」で、クリップボードのMarkdownのリストが項目になる。1つ目はカーソルの位置に続き、2つ目からは下の新しい項目になる
  - アプリがコピーした親と子は、親と子の形のまま戻る
- クリップボードの画像を貼ると、画像は`assets`フォルダーに保存され、カーソルの位置にそのリンクが入る
  - 画像は、来たときの名前で保存される。名前がなければ`image`と、種類の拡張子の名前になる。拡張子のない名前（写真の`IMG_0001`など）には、種類の拡張子が付く
  - 同じ名前の画像を2回貼っても、別々のファイルになる
  - 透明部分のあるHEICの画像（ステッカーなど）はPNGに、透明部分のないHEICの画像（写真）はJPEGに直して保存される

### 項目のメニュー

- 項目を長押しすると、項目のメニューが出る
  - 「Delete」は項目を消す
  - 「Send to Stash」は、項目を、ページの終わりの`# Stash`の見出しの下へ送る
  - 別の項目を見せている項目には、「Remove Transclusion」もある。選ぶと、その項目は空の項目になり、見せていた項目は残る

### 道具を使う

- 編集しているときと、項目を選んでいるときに、画面の下に道具が出る
  - 道具には、折りたたみ、タスク、項目を動かすパッド、カーソルを動かすパッド、元に戻す、やり直す、縮める、キーボードを閉じる、がある
  - 削除の道具はない
- キーボードを閉じる道具は、編集を終える。項目は選ばれたまま残り、背景に色が付く
  - キーボードを出す道具を押すと、選んでいた項目の編集に戻る
- 項目を動かすパッド
  - 右は字下げ、左は字下げを戻す
  - 上と下は、項目を隣の項目と入れ替える
  - 押し続けると、項目は動き続ける
- カーソルを動かすパッド
  - ←と→は、カーソルを1文字ずつ動かす。絵文字は1文字として数える
  - 項目の先頭での←は前の項目の末尾へ、末尾での→は次の項目の先頭へ移る
  - ↑と↓は、上と下の行へ動かす。最初の行の↑は前の項目へ、最後の行の↓は次の項目へ移る。行の中の位置は変わらない
  - 押し続けると、カーソルは動き続ける
- パッドの形
  - 矢印の絵の上でなくても、角から角への線で4つに分けた範囲が、それぞれの矢印になる
  - 真ん中の3分の1に触れても、何も動かない
- タスクの道具は、項目をタスクにする。押すたびに状態が進み、最後はタスクでなくなる
- 折りたたみの道具は、子を隠すと「Expand」になる。もう一度押すと、子が戻る
  - 子のない項目では押せない
- 元に戻すは最後の変更を取り消し、やり直すはそれをまた行う
- 項目を選んでいる間
  - カーソルを動かすパッドの上下で、選ぶ項目が上や下の項目に変わる。色も移る
  - 項目を動かすパッドは、選んだ項目を動かす
  - 「Copy」と「Cut」の道具が出る。選んだ項目をMarkdownのリストでクリップボードに載せる。「Cut」は項目をページから消す。編集しているときは出ない
  - 項目に触れると、選択は終わり、その項目の編集になる
- 縮める道具を押すと、道具は丸いボタンだけになる。丸いボタンを押すと、道具が戻る
  - 縮めたかどうかは、編集と選択を行き来しても変わらない

## Android版

### Dropboxにサインインする

- 入れたばかりのアプリは、「Sign in to Dropbox」のボタンだけを出す。上端のバーは出ず、今日のジャーナルも作らない
  - ボタンを押すと、サインインが始まる
- ブラウザでサインインを終えてアプリに戻ると、同期が始まる。サインインは、アプリを開き直しても残る
- サインインのあとの最初の同期が終わると、今日のジャーナルが開き、上端のバーが出る
- メニューの「Sign out」でサインアウトすると、「Sign in to Dropbox」のボタンに戻り、メニューは消える
  - 取り込んだページは、そのまま読める
  - サインアウトのあとは、同期しない。アプリが前に出ても、前のサインインは戻らない。次にサインインすると、Dropboxのファイルを初めから取り直す

### Dropboxと同期する

- アプリは、前に出るたびに同期する。後ろへ回るときも、書いたものを上げるために同期する
  - 端末を回したときなど、画面を作り直すだけのときは同期しない
- メニューの「Sync」で同期する。同期のあと、Dropboxのページが検索で見つかる
  - アプリのフォルダーで変わったページは、次の同期でDropboxに上がる
- アプリでページを作ったり書いたりすると、少し待ってから同期し、そのページがDropboxに上がる
  - キーボードが語を変換している間は、同期は始まらない。変換が終わってから待ち、同期する
- アプリが前に出たときの同期では、ファイルを運ぶ間、進み具合がダイアログに出る（例: 「Downloading 2 of 5」「Uploading 1 of 2」）
  - 運ぶファイルがまだ分からない間は、ダイアログは出ない
  - 編集のあとの同期では、ダイアログは出ない。進み具合は、ページの上の知らせに出る
- 同期の知らせ（例: 「Syncing…」）は、ページの上端の近くに、右へ寄せて出る
- 同期が動いている間は、メニューの「Sync」と「Sign out」は押せない
- 項目を編集している間も、メニューを開ける。開いても、編集は続き、キーボードは消えない
- 同期に失敗すると、知らせが出る
  - 通信できないときは「Sync failed: no connection」、ほかの理由では「Sync failed」とだけ出る。理由の長い言葉は出ない
  - 知らせの「Try again」で、同期をやり直せる
  - 失敗したあとのメニューには、「Sign in to Dropbox」が出る。Dropboxが受け付けなくなったサインインを、やり直せる
- 開いているページがダウンロードで変わると、画面に触れなくても新しい項目が出る
  - ほかの端末が項目の文だけを書き換えたときも、同じである
  - 項目を編集している間も、ほかの項目の変更は出る。編集は続く
  - 編集中の項目がほかの端末で書き換わると、こちらで打っていなければ、入力欄にその文が出る。カーソルは同じ文字数の位置に残り、続けて打てる
  - 編集中の項目にこちらで打った文は、ほかの端末が書き換えても残る

### ページを開く

- アプリは、前に見ていたページで開く。前のページがないときや、消えていたときは、今日のジャーナルで開く
- アプリを離れて開き直しても、すぐに開く
- 検索の入力欄
  - 取り込んだページが結果に出る。触れると、そのページが開く
  - 入力した名前のページがなければ、作る結果が出る。触れると、そのページができて開く
  - 作れない名前では、ページを作らず、訳を「OK」だけのダイアログで知らせる
  - 「today」と打つと、今日のジャーナルを開く結果が出る
- 今日のボタンは、今日のジャーナルを開く。なければ作る
  - 今日のページで下に続く過去の日付は、今日の日付と同じ大きさで出る
- 上端のバーに、戻るボタンと進むボタンがある
  - 戻るで前のページが開き、進むで戻る前のページが開く
  - 戻る先も進む先もないときは、ボタンは出たまま押せない。ページを2つ開くと戻るが押せ、戻ると進むが押せる

### リンクに触れる

- ページへのリンクに触れると、そのページが開く。`.md`への相対リンクでも同じである
  - まだないページへのリンクでは、そのページができて開く
- タグに触れると、そのタグのページが開く
- Webへのリンクに触れると、ブラウザで開く。http以外のリンクも、開く先に渡る
- `assets`のファイルへのリンクに触れると、そのファイルが端末のほかのアプリで開く。名前の大文字と小文字は問わない
  - ほかのアプリは、ファイルを読むことだけができる
  - ファイルの種類は拡張子で決まる。拡張子が大文字でもよい。種類が分からなければ、どのアプリでも選べる
  - 開けるアプリがなくても、アプリは落ちない
  - ファイルがなければ「No file yet: assets/none.pdf」のように知らせ、何も開かない

### 項目を装飾つきで読む

- 項目は、飾りの付いた文字で出る。Markdownの記号は出ない
  - 見出しは、レベルに応じて大きくなる
- コードブロックは、書かれたとおりの行で出る。フェンスの記号は出ない
  - リストの中のコードブロックも同じである。リストの番号は残る
- 表は、セルごとに出る。セルの中の文字にも飾りが付く。引用の中の表も同じである
- `assets`の画像は、前後の文字の間に、絵として出る。名前の大文字と小文字は問わない
  - 空白や日本語の名前の画像も、URLの形で書いた画像も出る
  - ページが幅を決めていれば、その幅で出る。なければ、画像そのものの幅で出る
  - ページが高さを決めていれば、その高さで出る。高さだけなら、幅は画像の形に従う
  - 絵の上の1行目に、代わりの文字（alt）が出る。altがなければ、ファイルのパスが出る
  - 1行目に触れると、その項目の編集になる
  - 絵に触れると、大きく開く。開いた絵に触れると、閉じる
  - ファイルのない画像は、代わりの文字が出る
  - Webの画像は描かず、代わりの文字のリンクになる
  - リストの中の画像も、絵として出る。リストの中のリストでも同じである
- タスクには、状態の印が付く。まだ始めていない、進行中、済みの3つである
  - 印は、項目の文字と同じ高さにある
  - 印に触れると、次の状態へ進む。編集には入らない
- 点（バレット）は、文字の高さの真ん中にある。見出しでは、大きな文字の真ん中の高さにある
- 子を隠した項目の点は、大きな薄い円の上に描かれる。子を戻すと、円は消える

### 項目を書く

- 項目に触れると、その項目がMarkdownの入力欄になる
  - 文字に触れると、触れた文字のMarkdownでの位置から書ける
  - ほかの項目に触れると、編集がそこへ移る。前の項目は、飾りの付いた表示に戻る
- 打った文字は、ページのファイルに書かれる
  - アプリが裏に回ると、保存を待っていた文字も、すぐにファイルに書かれる
- 開始記号を打ち終えると、閉じる記号が補われる
- 改行は、カーソルの位置で項目を分け、入力は下の新しい項目で続く。絵文字は1文字として数える
  - 空の子の項目での改行は、項目を1段外へ出す。次の改行で、新しい項目ができる
  - 長いページの末尾で改行すると、画面は新しい項目まで動く
- 項目の先頭でのBackspaceは、前の項目につなぐ。編集はつないだ項目で続き、カーソルはつなぎ目に置かれる
  - つなぎ目の位置では、絵文字を1文字として数える
  - 空の項目では、その項目が消え、前の項目の終わりで編集が続く
  - 先頭より後ろでのBackspaceは、前の1文字を消すだけである
  - 先頭から文字を選んでいるときは、選んだ文字を消すだけで、項目をつながない
  - 最初の項目の先頭では、何もしない
  - 画面のキーボードのBackspaceでも、同じに動く。押し続けても、カーソルは残った文字の末尾にある
  - ほかの項目が写している項目がつなぐことで消えるときは、先に尋ねる。「Cancel」なら項目は残り、「Delete」なら消える

### 貼り付ける

- Markdownのリストを項目の終わりに貼り付けると、1つ目はその項目に続き、2つ目からは下の新しい項目になる
  - 文字のメニューの貼り付けでも、実のキーのキーボードのCtrl+Vでも同じである
  - コピーの道具でコピーした親と子は、親と子の形のまま戻る。画面のキーボードのクリップボードの候補から入れても同じである
- 文字を選んで貼り付けると、選んだ文字が貼り付けた文字に置き換わる
- クリップボードの画像を貼ると、画像は`assets`フォルダーに保存され、項目にそのリンクが入る。画面のキーボードが入れた画像も同じである
  - 画像は、来たときの名前で保存される。名前がなければ、種類の拡張子の名前になる。画像でなければ、`image`という名前になる
  - 同じ名前の画像を2回貼っても、別々のファイルになる

### 道具を使う

- 道具は、編集しているときと、項目を選んでいるときだけ出る
  - 削除の道具はない。項目を消すのは、空の項目の先頭でのBackspaceである
- キーボードを閉じる道具は、編集を終える。項目は飾りの付いた表示に戻り、選ばれたまま残る
  - キーボードを出す道具を押すと、選んでいた項目の編集に戻る
- 項目を動かすパッド
  - 右は字下げ、左は字下げを戻す。編集は続く
  - 上と下は、項目を隣の項目と入れ替える
  - 押し続けると、項目は動き続ける
- カーソルを動かすパッドは、編集しているときだけ出る
  - ←と→は、カーソルを1文字ずつ動かす。絵文字は1文字として数える
  - 項目の先頭での←は前の項目の末尾へ、末尾での→は次の項目の先頭へ移る
  - ↑と↓は、上と下の行へ動かす。最初の行の↑は前の項目へ、最後の行の↓は次の項目へ移る。行の中の位置は変わらない
  - 押し続けると、カーソルは動き続ける
- パッドの形
  - 矢印の絵の上でなくても、角から角への線で4つに分けた範囲が、それぞれの矢印になる
  - 真ん中の3分の1に触れても、何も動かない
- タスクの道具は、項目をタスクにする。押すたびに状態が進む
- 折りたたみの道具は、子を隠すと「Expand」になる。もう一度押すと、子が戻る
  - 子のない項目では押せない
- 元に戻すは最後の変更を取り消し、やり直すはそれをまた行う
- 項目を選んでいる間
  - 選んでいる項目は、色で示される。選び直すと、色も移る
  - 2つ目のパッドの上下で、選ぶ項目が上や下の項目に変わる
  - 項目を動かすパッドは、選んだ項目を動かす
  - コピーと切り取りの道具が出る。選んだ項目をMarkdownでクリップボードに載せる。切り取りは項目をページから消す。編集しているときは出ない
- 縮める道具を押すと、道具は丸いボタンだけになる。丸いボタンを押すと、道具が戻る
  - 縮めたかどうかは、編集と選択を行き来しても変わらない

## 付箋紙（macOS・Windows）

### 付箋紙を机に並べる

#### 付箋紙を開く

- 何も保存されていないときは、ページのない付箋紙が1つ開く
- 前の付箋紙は、次の起動で、ページ、位置、大きさ、色、ズーム、常に手前に表示とともに戻る
  - macOSでは、タイトルバーだけにした付箋紙は、タイトルバーだけで戻る。ダブルクリックで元の大きさに戻る
  - Windowsでは、最小化した付箋紙は、最小化する前の位置と大きさで戻る

#### 付箋紙を足す

- タイトルバーの新しい付箋紙のボタンと Cmd+N（Windows は Ctrl+N）で、ページのない付箋紙を足す
  - 足した付箋紙は、押した付箋紙の左上隅から少し右下に出る。最後に開いた付箋紙の右下ではない
  - 足した付箋紙は、前の付箋紙にぴったり重ならない
  - スクリーンからはみ出るときは、全体がスクリーンに収まる位置まで戻る
  - スクリーンより大きい付箋紙は、左上の隅がスクリーンの左上の隅に合う。タイトルバーが隠れない
- 付箋紙は、それぞれが自分のページを持つ。1つでページを開いても、ほかの付箋紙は変わらない

#### 付箋紙を閉じる

- タイトルバーの閉じるボタンで閉じた付箋紙はなくなり、次の起動でも戻らない。ほかの付箋紙は残る
- 閉じる前に、まだ保存していなかった本文がサーバーに保存される
- アプリを終えても、付箋紙はページと位置を持って、次の起動で戻る。アプリを終えるときも、まだ保存していなかった本文は保存される
  - Windowsでは、Ctrl+Q でアプリを終える
  - Windowsでは、Alt+F4 で閉じた付箋紙は、次の起動で戻る

### 付箋紙でページを読む

#### ページを開く

- ページのない付箋紙には、検索欄が最初から出ていて、カーソルがそこにある
- 検索欄に入力すると、少しあとにページの候補が出る。下矢印で選んで Enter で開くか、候補をクリックして開く。開くと検索欄は閉じ、文字は消える
  - macOSでは、タイトルバーの検索のツールで検索欄が出る
  - Windowsでは、Ctrl+F か検索ボタンで検索欄が出る
  - 候補が出ているときの Escape は候補を隠す。macOSでは、候補がないときの Escape は検索欄を閉じる
  - macOSでは、探し終えて何も見つからなかったときだけ、見つからないと出る
  - macOSでは、見つけた文の前後が、ページの名前の下に出る。名前で見つけたページでは出ない
  - macOSでは、候補がウィンドウに入りきらないときも、検索欄はウィンドウの中にとどまる
  - macOSでは、いま開いているページを選ぶと、検索欄の文字が消える
- 作れない名前のページを検索から作ろうとすると、知らせが出る
- 新しいページには、空の項目が1つある
- サーバーがアプリよりあとに上がっても、上がるとページが読み込まれて出る
- macOSでは、ページを開いているときにサーバーにつながっていなければ、そう出る。つなぎ始めは、つないでいる途中と出る。ページのない付箋紙には出ない

#### 今日のジャーナルを読む

- 今日のジャーナルの題は、今日の日付に「(Today)」を付けたものである。今日でない日のジャーナルの題は、その日付だけである
- 今日のジャーナルを前の日までスクロールすると、題はその日の日付になり、「(Today)」は付かない。今日まで戻ると、また付く
- 前の日の最初の項目の上に、その日の日付が見出しとして入る。macOSでは、区切り線も入る
- Windowsでは、スリープからの復帰と時刻の変更で、日付が変わったかを確かめる。同じ日のうちは、今日のジャーナルは開き直さず、編集中の項目もそのまま残る

#### リンクをたどる

- 編集していない項目のウィキリンクをクリックすると、そのページがその付箋紙で開く。Option（Windows は Alt）を押しても同じである
- ハッシュタグをクリックすると、タグのフォルダーにあるそのタグのページが付箋紙で開く
- Cmd-クリック（Windows は Ctrl-クリック）で、そのページを新しい付箋紙で開く。新しい付箋紙は、たどった付箋紙の左上隅から少し右下に出る。たどった付箋紙のページは変わらない
- Shift-クリックで、そのページを Web 版でブラウザに開く。付箋紙のページは変わらない
- 外へのリンクと assets のファイルへのリンクは、ブラウザで開く。項目は編集にならず、ページもそのままである
- macOSでは、編集中に Cmd+O で、カーソルのあるウィキリンクのページを付箋紙で開く
- 戻ると前に開いたページがまた開き、進むと戻る前のページに戻る。履歴は付箋紙ごとにあり、次の起動ではいま開いているページが戻る
  - macOSでは、タイトルバーの戻ると進むの矢印は、行き先があるときだけ押せる。フォーカスのない付箋紙では、見えない矢印の場所を押しても戻らない

#### 装飾付きで読む

- 編集していない項目は、Markdown の記号なしで装飾付きで出る。文字の色は、編集中の項目と同じである
- 見出しは、大きな太字で出る
- リストの項目と引用の中は、右に寄る。中身のないリストの項目も、印は出る。Windowsでは、引用の中は薄い文字になる
- 区切り線は、線で出る
- 太字、斜体、取り消し線、下線、マーカー、伏せ字、上付き、下付き、コードの字体で出る。上付きと下付きは小さな文字になる
- 表は、セルごとに枠のある格子で出る。見出しの行は太字である。行のない表は何も出ない
- assets の画像は、絵として出る
  - 届くまでは、代替の文字が出る。代替の文字がなければ、ファイルの名前が出る
  - 大きさを求めない画像は、付箋紙の幅に合わせる。元の大きさより大きくはならない
  - 幅か高さを求めた画像は、それに合わせ、縦横の比を保つ
- 本文のない項目は、何も出ない

### 付箋紙に書く

#### 項目を書く

- 表示した文字に触れると、その項目の編集に入り、触れた文字の位置にカーソルが入る
  - 区切り線に触れると、その項目の先頭にカーソルが入る
  - 編集中の項目をクリックすると、カーソルはクリックした文字のそばに移る
  - macOSでは、編集中の項目を Shift-クリックすると、カーソルからクリックした文字までが選ばれる
- 打った文字は、少しあとにサーバーに保存される
- macOSでは、変換中の文字は、画面が描き直されても消えない
- Enter で、カーソルの位置で項目を分ける。カーソルは新しい項目の先頭に移る
  - macOSでは、Enter のすぐあと、項目が分かれる前に打った文字や Enter も、新しい項目に入る
- Shift+Enter で、項目を分けずに項目の中で改行する
- 先頭での Backspace で、項目を前の項目につなぐ。カーソルはつなぎ目に置かれる
- 末尾での Delete で、次の項目をつなぐ
- 上矢印は、前の項目へ同じ位置のまま移る。最後の行での下矢印は、次の項目へ移る
  - 2行ある項目の2行目や、末尾の改行のあとの空の行での上矢印は、項目の中で上の行へ動く
- 先頭での左矢印は前の項目の末尾へ、末尾での右矢印は次の項目の先頭へ移る
- 開始記号を打ち終えると、閉じる記号が補われる
- 本文が1行の見出しである項目は、編集中も見出しの大きさの太字で出る。記号はそのまま見える
- 項目から検索欄へ移り、また項目に戻ると、項目はもう一度編集中になる
- サーバーの拡張が確認を求めると、質問が出る。「いいえ」では何も起きず、「はい」で先へ進む

#### 構造を整える

- Tab で項目を字下げし、Shift+Tab で字上げする。文字は入らない
- Shift+Option+上下（Windows は Shift+Alt+上下）で項目を上下に動かす。カーソルはその項目に残る
- Cmd+上（Windows は Ctrl+上）で子の項目を隠し、Cmd+下（Windows は Ctrl+下）で表示する。切り替えではない。カーソルは文の中で動かない
  - macOSでは、子を隠した項目のバレットは、二重の円である
- Ctrl+Enter で項目をタスクにし、押すたびに状態を進める。文字は入らない。macOSでは、Cmd+Enter でも同じである
  - タスクの印をクリックすると、状態が進む。項目を編集していなくてもよい
  - macOSでは、タスクの前にもバレットが出て、そのあとにタスクの状態が並ぶ。進行中は横線の入った箱、完了はチェックの入った箱で出る
- 編集中でない空の項目には、バレットが見えない。文字のある項目と、編集中の項目には見える

#### 取り消す

- Ctrl+Z で元に戻し、Shift を足してやり直す。macOSでは、メニューの「取り消す」と「やり直す」でもでき、項目の中でいつも選べる
- ほかで表示されている項目を消すときは、確認を求められる
  - Windowsでは、OK で消える。確認のダイアログでの Enter は取り消しになり、何も消えず、選択も残る

#### 選んで扱う

- 最初の行での Shift+上で、その項目を選ぶ。Shift+上下で選択が広がり、Escape で選択が消える
- 項目の文字から別の項目までドラッグすると、またいだ項目が選ばれる
  - macOSでは、項目の中だけのドラッグは文字を選び、項目は選ばない。付箋紙の下端にかかった項目の中で文字をドラッグしても、スクロールしない
  - macOSでは、ドラッグで項目を選んでも、打っていた文字は保存され、選んだ項目を動かしても消えない
- macOSでは、ドラッグ選択のマウスを付箋紙の上端か下端で止めると、その向きへスクロールし、出てきた項目まで選ばれる
- macOSでは、ドラッグ選択のマウスが付箋紙の上の外へ出ると、見えているいちばん上の項目まで選ばれる。まだ見えていない項目は選ばれない
- 選んでいるあいだの Backspace か Delete で、選んだ項目を消す
- 選んでいるあいだの Shift+Option+上（Windows は Shift+Alt+上）で、選んだ項目を上へ動かす
- 選んでいるあいだの Cmd+C（Windows は Ctrl+C）で、選んだ項目を Markdown としてコピーする。macOSでは、メニューの「コピー」でもできる
  - 同じ内容の HTML もコピーされる。ウィキリンクとハッシュタグは、Web 版のページを開くリンクになる
- 選択は、項目の文字のクリックで消え、その項目に入力できる。項目の外や項目のないところのクリックでも消える。項目は消えない
  - Windowsでは、検索ボタンやタイトルバーのクリックでも、選択が消える

#### 貼り付ける

- Cmd+V（Windows は Ctrl+V）で、Markdown のリストを項目に分けて、カーソルの位置に貼る。macOSでは、メニューの「ペースト」でもできる
  - 絵文字のすぐ後ろのカーソルでも、カーソルの位置に貼る
- Shift+Cmd+V（Windows は Ctrl+Shift+V）で、文字をそのまま1つの項目に貼る。macOSでは、メニューの「ペーストしてスタイルを合わせる」でもできる
- 親と子を選んでコピーし、別の項目の終わりに貼ると、親と子の形のまま戻る
- クリップボードの画像は、サーバーの assets に保存され、カーソルの位置にそのリンクが入る。カーソルが項目を離れると、画像で出る
  - macOSでは、Finder でコピーした画像のファイルも貼れる。HEIC の画像は、ブラウザで見られる形に直して保存される。元のファイルは残る
  - macOSでは、文字もあるクリップボードでは、画像ではなく文字を貼る。画像でないファイルのコピーでは、画像を貼らない
- Windowsでは、画像のファイルをドラッグ＆ドロップで入れられる。元のファイルは残る
  - 編集中の項目に落とすと、落とした文字の位置にリンクが入る。編集していない項目に落とすと、本文の末尾にリンクが入る
  - 落としたファイルの中で、最初の画像だけが入る。画像がなければ、何も入らない
- Windowsでは、編集していない項目の右クリックのメニューの「Paste as Transclusion」で、コピーした項目をトランスクルージョンとして貼る

### 付箋紙の見た目を整える

#### 色を変える

- 新しい付箋紙は黄色である。9色と、そのあとの透明から、付箋紙の色を選ぶ。今の色には印が付く
- 透明を選ぶと、後ろのウィンドウが透けて見える。色を戻すと、透けなくなる
- 透明な付箋紙は、フォーカスがないとき、書かれた文字だけを見せる。クリックしてフォーカスが戻ると、また出る。色のある付箋紙は、何も隠さない
  - macOSでは、タイトルバーの名前とツール、バレット、スクロールバー、ウィンドウの影が隠れる。フォーカスのない付箋紙をメニューで透明にしても、すぐに隠れる

#### 大きさを変える

- タイトルバーのダブルクリックで、タイトルバーだけに巻き上げる。もう一度で、元の大きさに戻る。上の端と幅は変わらない
  - macOSでは、タイトルバーの名前の上をダブルクリックしても巻き上げる。すばやくクリックし続けると、2回目で巻き上げ、4回目で戻る。ウィンドウは大きくならない
  - 紙の上のダブルクリックでは、大きさは変わらない
  - Windowsでは、画面いっぱいの付箋紙は、タイトルバーのダブルクリックで元に戻る。巻き上げはしない
- Windowsでは、最大化のボタンで画面いっぱいになり、もう一度押すと元に戻る。最小化のボタンで最小化する
- ズームすると、項目の文字が大きくなる。縮小すると小さくなる。等倍に戻せる
  - ズームは1回で1割ずつ変わり、30% から 300% までである
- 常に手前に表示すると、付箋紙はほかのウィンドウの上にとどまる。やめると、普通のウィンドウに戻る

#### メニューを開く

- タイトルバーの右クリックで、付箋紙のメニューが出る。常に手前に表示する項目と、付箋紙の色が並ぶ
  - 常に手前に表示しているときは、その項目に印が付く
- macOSでは、編集していない項目の右クリックか Control-クリックでも、付箋紙のメニューが出る。項目は編集に入らず、カーソルは元の項目に残る。何も押さないクリックでは出ない

#### 道具を隠す

- macOSでは、フォーカスがないときは、タイトルバーの検索のツールと、閉じる・しまう・大きくするボタンが隠れる。フォーカスが戻ると出る。新しい付箋紙のボタンは残る
- macOSでは、タイトルバーだけにしている間は、閉じる・しまう・大きくするボタンと検索のツールが隠れる。元に戻すと出る

## todoアプリ

### 起動と接続

- 既定では、画面を配信したjournal-serverにつなぐ
  - URLのクエリ`?host=`と`?port=`を付ければ、そのサーバーにつなぐ。片方だけでもよい。`host`がなければ`localhost`、`port`がなければ`8087`である
- 下の欄に、接続の状態（disconnected、connecting、connected）を出す
  - 接続が切れると、3秒ごとにつなぎ直す
- 接続すると、終わっていないタスクを読んで出す
  - サーバーでページが変わると、タスクを読み直す

### タスクの一覧

- タスクは開始日の早い順に、開始日の見出しの下に並ぶ
  - 同じ開始日のタスクは、1つの見出しの下に並ぶ
  - 開始日のないタスクは、最後に「開始日なし」の見出しの下に並ぶ。そういうタスクがなければ、この見出しは出ない
- タスクがなければ、「No items found」と出す
- 読み込みに失敗すると、「Error: 」に続けてわけを出す
  - サーバーが失敗のわけを返さなければ、HTTPのステータスを出す
  - 次に接続を試みると、エラーは消える。接続が切れただけでは消えない
- 絞り込みを続けて変えたとき、前の読み込みの答えや失敗が後から来ても、画面には出ない

### 絞り込み

- Doneにチェックすると、終わったタスクも出す
- 開始日を選ぶと、その日より後に始まるタスクは隠れる。その日に始まるタスクと、開始日のないタスクは出る
  - 日を選ばなければ、先の日に始まるタスクも出る
- 日誌のタスクは最初から出ていて、Journalのチェックを外すと隠れる。日、週、月、年の日誌のどれも同じである
- 文書のページのタスクは、Pageにチェックすると出る。名前が日付の形でも、文書のページならPageで決まる

### タスクの行

- ページの名前と、開始日（「開始: 」）と期限（「期限: 」）を出す
- 状態のバッジを出す。開始も終了もなければTODO、開始だけならRUNNING、終了があればDONEである
- 行をクリックすると、PetaJournalでそのタスクのページを開く
- 本文のウィキリンクはPetaJournalのWebアプリのページへ、タグはタグのページへのリンクになる。リンクをクリックしても、タスクのページは開かない
  - 本文の画像は、ページの置き場所から読む
- バッジをクリックすると、タスクの状態を次へ進める。タスクのページは開かない
  - 失敗すると、エラーを出し、タスクは元の状態のまま残る

## memoview（Windows）

### ページの表示

- 項目は、ページの順に1行ずつ出る
  - 折りたたまれた項目の子孫は出ない。そのあとの項目は出る
  - 本文のない項目は、空の行になる
- 行の先頭の印
  - 子のない項目には黒丸が付く。見出しには黒丸が付かない
  - 子のある項目には、黒丸の代わりに折りたたみの矢印が付く。開いているときは下向き、折りたたまれているときは右向きである
- タスク
  - タスクには、黒丸の代わりにチェックボックスが付く。タスクでない項目には付かない
  - 開始も終了もなければTODOで、チェックボックスは空である。開始だけならRUNNINGで、横線が入る。終了があればDONEで、チェックが入る。値が空の時刻は、ないものとして扱う
  - 子のあるタスクには、チェックボックスの左に折りたたみの矢印が付く
- 付箋紙の色が、ページの背景になる
- アクティブでない付箋紙は、スクロールバーを出さない
- ページの代わりに見せる文（案内やエラー）は、HTMLではなく文字のまま出る

### リンクと画像

- ウィキリンクとハッシュタグは、サーバーの設定どおり、PetaJournalのWebアプリのページへのリンクになる
- ページからの相対パスで書かれた画像は、サーバーから読む

### ページでの操作

- ズームを変えられる。倍率は、OSの言語によらず正しく効く
- 折りたたみの矢印をクリックすると、その項目を開いたり折りたたんだりする
- ウィキリンクやハッシュタグをクリックすると、そのページを開く
  - `http`と`https`のほかのURLは開かない

### 付箋紙の設定

- 足した付箋紙は、次に起動しても残る
- 消した付箋紙は、次に起動しても出てこない。ほかの付箋紙は残る
  - 閉じる途中の付箋紙が位置やサイズを保存しても、消した付箋紙は戻らない

## サーバー（journal-server）

### 起動の設定

- `--port`で待ち受けるポートを決める
- `--throwaway-dir`を渡すと、使い捨てのサーバーになる
  - データ（`data/`、DBは`data/journal.db`）、索引（`index/`）、設定（`config/`）、Markdownフォルダー（`markdown/`）が、そのフォルダーの下に決まる
  - `--data-dir`、`--db`、`--index-dir`、`--config-dir`と一緒には使えない
  - 設定ファイルが外のMarkdownフォルダーを指していても、自分のフォルダーの下の`markdown/`を使う。外のフォルダーには何も書かない
  - 外のMarkdownフォルダーへの設定の変更は受け付けず、答えも今のフォルダーのままである。自分のフォルダーの下への変更は受け付ける
  - この機械からの接続だけを受ける
- `--throwaway-dir`のないサーバーは、Markdownフォルダーを設定ファイルのとおりに読み、どこからでも接続を受ける
- この機械だけから受けるサーバーは、IPv6とIPv4のループバックだけで待ち受け、どちらからの接続も受ける
- `--frontend-dir`で、配信する画面のフォルダーを決める
  - 指定がなければ、実行ファイルの隣の`frontend/`を使う。それもなければ、画面は配信しない
  - 指定したフォルダーは、実行ファイルの隣の`frontend/`より優先される
- Markdownフォルダーには、`assets/`、`docs/`、`journals/`のフォルダーが作られる。フォルダーが設定されていなければ、何も作らない

### 手で実行するコマンド

- サーバーを止めて実行する`write-pages`は、すべてのページのMarkdownファイルを今のサーバーの形で書き直す
  - 項目の更新日時が書かれていないファイルに、それが書かれる。項目は変わらない
  - まだ取り込まれていないファイルの編集は、先に取り込まれ、失われない
  - 書いたファイルの数と、ページの数を伝える（`1 of 3 page files written`）
- サーバーを止めて実行する`asset-names`は、`assets/`のファイルをIDの名前に変え、リンクも書き換える。対応表のファイルを`--file`で渡す
  - `plan`は、対応表をファイルに書くだけで、ノートは変えない
    - 新しい名前は、ファイルの日時から作ったIDと、元の拡張子である。日時は更新日時と作成日時の古いほうで、古いファイルから並ぶ
    - すでにIDの名前を持つファイルは、対応表に入らない
  - `apply`は、対応表のとおりに、ファイルとリンクを変える
    - 項目の本文、ページのMarkdownファイル、検索の結果の本文のリンクが、新しい名前を指す。項目とページの更新日時は変わらない
    - 書き換えたあとでフォルダーを走査しても、取り込むものはない
    - まだ取り込まれていないファイルの編集は、先に取り込まれ、失われない
    - ファイルがすでに新しい名前になっていても、リンクは書き換わる
  - `revert`は、対応表を逆にたどって、ファイルとリンクを元に戻す

### APIの共通の決まり

- 変更を送るクライアントは、`X-Client-Id`ヘッダーでUUIDのIDを名乗る
  - IDを名乗らない変更は400で断られ、メッセージが`X-Client-Id`ヘッダーを挙げる。何も変わらない
  - データを変えないPOSTも、PUTも、DELETEも、IDがなければ断られる。UUIDでない値も断られる
  - GETは、IDがなくても答える
  - ファイルが消えたときの確認ページのフォームは、IDがなくても受け付ける
  - ほかのオリジンのページは、`X-Client-Id`ヘッダーを付けたリクエストを送ってよい
- APIでの変更は、`/api/events`のストリームで、変更したページのidとともに知らされる
  - 知らせの`source`は`app`で、`clientId`は変更を送ったクライアントのIDである
- 日付（`createdDate`、`modifiedDate`）は、既定ではミリ秒の数である
  - クエリ`dateFormat=iso`で、ページと項目の日付がUTCのISO 8601の文字列になる。ほかの値は変わらない。`dateFormat=millis`は既定と同じである
  - 変更のルートも、同じクエリを受ける
  - 利用者のプロパティは、日付の欄と同じ名前でも書き換えられない
  - 知らない形式は400で断られ、何も変わらない
  - イベントのストリームは、`dateFormat`があってもそのまま流れる
- `/api/`で始まり、ルートのないパスは404になる
- `GET /api/health`は、`status`が`ok`の答えを返す

### 項目

- 項目のルートは、正しい要求に200で答える。作成、取得、更新は`item`を、削除は204を返す
  - 移動（`move`）、バッチ（`batch`）、字下げ（`shift-level`）、貼り付け（`paste`）、スタッシュ（`stash`）は`items`を返す
  - 結合（`merge`）、トランスクルードの設定と解除（`transclude`）、タスクの状態を進める操作（`cycle-task`）、プロパティの設定と削除は`item`を返す
  - 分割（`split`）とまとめての削除（`items/delete`）は`created`を、トランスクルードの問い合わせ（`transcluded`）は`itemIds`を返す
- 型での一覧（`GET /api/items?types=task`）は、その型の項目を返す。型を指定しない一覧は空である
  - `withoutProperty`を渡すと、そのプロパティを持つ項目を除く。終えたタスクを`withoutProperty=end`で除ける
- 型での一覧、1件の取得、ページの取得は、`fields`で頼まれたフィールドだけを各項目に持つ。`items`、`item`、`page`の包みは変わらない
  - 名前は答えのJSONの名前である（例: `id`、`ast`、`body`、`level`、`parentItemId`）
  - 表示だけのクライアントは、本文のMarkdownを受け取らずに`ast`から描ける

### ページ

- ページのルートは、正しい要求に200で答える
  - `POST /api/pages/doc`はページを作るか見つけて、`page`と`items`を返す。`dirPath`に`フォルダー/`を渡すと、その下に作る
  - 最近のページ（`recent`）と子ページ（`children`）は`pages`を、名前での検索（`find`）は`page`を、バックリンク（`backlinks`）は`entries`を返す
  - ページのプロパティの設定と削除、改名、フォルダーのページを下ろす操作（`demote`）は`page`を返す
- 別のページと同じ名前への改名は409で断られる
- ページの削除は204で答え、消したページの取得は404になる

### アトラス

- アトラスのルート（`/api/pages/{id}/atlas/...`）は、正しい要求に200で答え、アトラスの`items`を返す
  - カードのリンクを足す、変える。カードをまとめる、まとまりを解く。まとまりの見出しを付ける
  - コールアウトを足す、変える。アトラスの項目を消す

### ジャーナル・検索・設定

- `POST /api/journals/{日付}`はジャーナルを作るか見つけて、`page`を返す。`/move`で項目をその日へ移す
- 日の前の直近のジャーナル（`before?date=`）と、週の前の直近のジャーナル（`weekly/before?week=`）は、`found`を返す
- ページ名の検索（`search/pages`）、本文の検索（`search/combined`）、タグの検索（`search/tags`）は、`results`を返す
- 設定の読み書きは`markdownDir`を含む答えを返す。プロパティ定義の一覧、追加、削除は`propertyDefinitions`を返す
- 拡張の問い合わせへの答え（`POST /api/confirm/{requestId}`）は、問い合わせが待っていれば200で答え、その答えが問い合わせに届く
  - 問い合わせはイベントのストリームで`requestId`とともに知らされる
  - 待っていない問い合わせへの答えは404になる

### Markdownとの変換

- 書き出し（`POST /api/items/export`）は、`treeMarkdown`と`flatMarkdown`だけを返し、ASTを持たない
- ページの書き出し（`export-page`）と部分木の書き出し（`export-subtree`）は、クエリでidを受ける
- 木のMarkdownの取り込み（`import`）は`flatMarkdown`を、Flat Markdownの解析（`parse`）は`items`を返す

### アセット

- `POST /api/assets/upload`で送ったファイルは、`assets/`にIDの名前で、中身のまま保存される
  - 答えには、保存した名前（`fileName`）と元の名前（`originalName`）がそのまま入る
  - 同じ名前のファイルを続けて送ると、別々の名前で保存され、どちらも残る
  - 50MBまでのファイルは保存される。50MBを超えるファイルは断られ、保存されない

### 画面の配信

- 画面のフォルダーのファイルは、その名前のパスで返る
- `/`と、ファイルのないパスには、`index.html`が返る
- `/api`、`/assets`、`/mcp`のルートは、同じパスにある画面のファイルより優先される
- `/apps/`のパスは拡張Webアプリとして扱われ、画面の`index.html`は返らない
- 画面のフォルダーがなければ、画面は配信されない
- `index.html`と、名前にハッシュのないファイルは、キャッシュされずに毎回確かめられる（`no-cache`）
  - ハッシュと同じ形を名前に含むページのパスに返る`index.html`も、キャッシュされない
- 名前にハッシュの付いたファイルは、長くキャッシュされる（`public, max-age=31536000, immutable`）

### 拡張Webアプリ

- 設定フォルダーの`apps/{名前}/`のファイルは、`/apps/{名前}/`の下のパスで返る。画面を配信していなくても返る
  - `/apps/{名前}/`には、そのアプリの`index.html`が返る
  - 拡張子のないパスでファイルがなければ、そのアプリの`index.html`が返る
  - 拡張子のあるパスでファイルがなければ、404になる
  - アプリのフォルダーがなければ、どのパスも404になる
- 末尾の`/`がない`/apps/{名前}`は、クエリを保ったまま`/apps/{名前}/`へリダイレクトされる
- 消したアプリのフォルダーは、起動し直さなくても配信されなくなる
- `..`をアプリの名前やパスにしても、`apps/`の外のファイルは返らない
- アプリのファイルは、名前にハッシュがあってもなくても、キャッシュされずに毎回確かめられる

### ファイルの同期

- 同期の状態（`GET /api/sync/status`）は、Markdownフォルダーの場所（`markdownRoot`）、それがあること（`rootAvailable`）、取り込みが有効なこと（`importEnabled`）を返す
- 走査（`POST /api/sync/scan`）は、取り込んだ数（`imported`）を返す
- フォルダーから消えたファイルは消えたものとして記録され、ページはユーザーが決めるまで残る
  - 消えたファイルは、確かめるページ（`/api/sync/pending-deletes`）に、そのページのidとともに並ぶ
- フォルダーを監視し、外で変えたファイルを、走査を待たずに取り込む
  - 外で編集したファイルはページに取り込まれ、検索で見つかる
  - フォルダーに置いた新しいファイルは、ページになる
  - シンボリックリンクを通して設定したフォルダーでも、リンクの先で編集したファイルが取り込まれる
  - 監視を始めたときに`docs/`も`journals/`もなかったフォルダーでも、あとでできた`docs/`のファイルが取り込まれる
  - ほかの端末が書いた`settings/properties.json`も取り込まれる。`settings/`がなければ作って見る
  - Markdownフォルダーの設定を変えると、すぐに新しいフォルダーを監視する
  - 空のファイルが先に作られても、ページは中身が書かれてから作られる
  - 読み込みに失敗したファイルは、新しい変更を待たずに取り込み直す。4回失敗すると諦め、走査に任せる。一度取り込めたファイルは、あとでまた失敗しても4回試す

### MCP

- `/mcp`で、Streamable HTTPのMCPサーバーとして答える
  - 接続したクライアントに、ツールを持つことと、`PetaJournal`で始まる説明を伝える
- RESTのルートとMCPのツールは、同じ操作を持つ。ツールはそれぞれ1つのルートの操作である
  - 画面やブラウザーのためだけのルートは、ツールを持たない。ヘルス、イベントのストリーム、名前でのページの検索、OSで開く操作、フォルダーの選択、問い合わせへの答え、消えたファイルの確認ページとそのフォームである
- ツールは、項目のASTを除いて、同じ操作のRESTのルートと同じJSONで答える
  - `fields`で`ast`を頼んでも、ASTは返らない。利用者の`ast`という名前のプロパティは消えない
  - 日付は既定でミリ秒の数で、引数`dateFormat`に`iso`を渡すとUTCのISO 8601の文字列になる。知らない形式は断られ、何も変わらない
- 項目を変えるツールの引数は、項目のIDと、RESTのルートが本文で受ける欄である（例: `update_item`は`itemId`が必須で、`body`、`collapsed`、`level`、`dateFormat`を受ける）
- 不正なIDは、invalid paramsとして断られる。ない項目やページは、`Item not found`、`Page not found`で断られる
- 項目のツール
  - `create_item`、`get_item`、`update_item`、`delete_item`で、項目を作り、読み、変え、消す。`update_item`で渡さない欄は変わらない。`delete_item`は`deleted: true`を返す
  - `move_items`は、項目をページの間で動かす。`levelDelta`で階層をずらし、なければそのままにする。空になったページには空の項目が1つ残る
  - `cycle_task`はタスクの状態を進め、`get_items_by_type`は型で一覧する。`get_items_by_type`は`fields`と`withoutProperty`を受ける
  - `set_transclusion`は元の項目の本文を映し、`remove_transclusion`で解くと本文は空になる。`get_transcluded_items`はトランスクルードされている項目を返す
  - `upsert_property`、`delete_property`で、項目のプロパティを設定し、消す
  - `paste_text`、`split_item`、`merge_items`、`shift_item_levels`、`apply_batch`、`delete_items`、`stash_item`で、エディターの操作をする。スタッシュは`# Stash`の見出しの下に項目を入れる
- Markdownのツール
  - `export_tree_markdown`、`export_subtree_markdown`、`export_page_markdown`は、木のMarkdownを返し、ASTを持たない
  - `import_tree_markdown`は、木のMarkdownをFlat Markdownにする。`parse_flat_markdown`は、Flat Markdownを項目に分ける
- ページのツール
  - `get_or_create_doc`は、ページを作るか見つける。作ったときは`created: true`で空の項目を1つ持ち、2回目は`created: false`で同じページを返す
  - `get_page_by_id`はページを返し、`fields`を受ける。`update_page`は改名し、`delete_page`は消して`deleted: true`を返す
  - `get_recent_pages`は、最後に触ったページを先に返す。`type`が空ならすべての型、`maxResults`が0なら10件である
  - `get_backlinks`は、ウィキリンクで指すページと項目を返す
  - `get_child_pages`、`upsert_page_property`、`delete_page_property`、`demote_page`で、子ページ、ページのプロパティ、フォルダーのページを下ろす操作を扱う
- アトラスのツール（`add_atlas_link`、`set_atlas_link`、`group_atlas_cards`、`ungroup_atlas_cards`、`set_atlas_group_title`、`add_atlas_callout`、`set_atlas_callout`、`remove_atlas_item`）で、カード、まとまり、コールアウトを作り、変え、消す
- ジャーナルのツール
  - `get_or_create_journal`は、名前でジャーナルを作るか見つける。ジャーナルの名前でなければ`Not a journal filename`で断られる
  - `get_most_recent_journal_before`は、日付の前の直近の日を返す。なければ`found: false`で、日付でなければ`Invalid date`で断られる
  - `get_most_recent_weekly_journal_before`は、週の前の直近の週を返す。`move_items_to_journal`は、項目をその日のジャーナルへ移す
- 検索のツール（`search_page_names`、`search_combined`、`search_by_tag`）は、`maxResults`の数まで返す。0なら既定の数である
- 設定のツール
  - `get_config`、`update_config`で、設定を読み書きする。答えには、設定から作るリンクの形（`wikilinkHref`、`hashtagHref`、`pagesBase`など）も入る
  - `get_property_definitions`、`add_property_definition`、`delete_property_definition`で、プロパティ定義を読み、足し、消す
- `get_sync_status`と`scan_folder`は、RESTの同期の状態と走査と同じJSONで答える
- `upload_asset`は、PCのファイルの絶対パスを受け、そのファイルを新しい名前でアセットに写す。元のファイルは残り、答えはRESTのアップロードと同じ形である
  - ファイルのないパスとフォルダーは`No file at`で、絶対でないパスは断られる
  - ちょうど50MBのファイルは写し、それを超えるファイルは断られる
- 項目を変えるツールとページを改名・削除するツールは、そのページの変更をイベントのストリームで知らせる。知らせの`source`は`mcp`である
