# PetaJournal Emacs版（アウトライナー）

## 概要（仮）

Emacs版は、ジャーナルサーバーにつながる Emacs のアウトライナーである。Emacs のバッファで、PetaJournal のページを読み、書く。Rust のプログラム（`outliner-emacs`）がコア（`client-core`）を持ってサーバーとやり取りし、Emacs のモード（`lisp/peta-journal.el`）が行を描き、キーを伝える。場所は `client/apps/emacs/outliner` である。

このストーリーマップは、2026-11-27 時点の Emacs 版のテストから逆算して作った。出典は、`lisp/test/peta-journal-test.el` と `lisp/test/peta-journal-e2e.el` の説明、`src/tests/*.rs`、`tests/process.rs` である。機能の一覧は `docs/features-emacs.md` にある。

## ペイン（仮）

- ふだん Emacs で書いている人は、ジャーナルもいつものキーで書きたい。ブラウザへ移ると、手が止まる。
- Emacs で書いたことも、ほかのクライアントと同じジャーナルのページとして残したい。Emacs だけの別のファイルにはしたくない。
- Markdown の記号は、書くときには見えてほしく、読むときには消えてほしい。

## ユーザーのタイプ（仮）

- 利用者 `#利用者`: Emacs で `M-x peta-journal` を実行して、ページを読み書きする人。

## Story map

1. アクティビティ
2. タスク
3. ウォーキングスケルトン
4. 毎日の記録
5. まとめて扱う
6. 知識の整理

- 今日を書き始める #利用者
  - // 出典: peta-journal-test.el, peta-journal-e2e.el, src/tests/shell.rs, src/tests/emacs_text.rs
  - アプリを開く
    - 起動すると、今日のジャーナルが1つのバッファにページ全体で開く
      - 日付が変わると、新しい日のジャーナルが開く。フレームにフォーカスが戻ったときも、日付を確かめる
  - 項目を書く
    - 打った文字は保存され、`C-x C-s` で編集を終えるとすぐに保存される
      - ^ 各項目はバレットと本文で描かれ、字下げはレベルの分の幅で見える
        - ^ カーソルは、バレット、項目の区切り、日付の行に留まらず、項目の本文へ移る
          - `[[` や ```` ``` ```` を打つと、閉じる記号が補われる
            - ^ 長い本文は、バレットの行から始まる。空白のない日本語も長い URL も、バレットだけの行を作らない
    - Enter で項目を分け、カーソルは新しい項目の先頭へ移る
      - ^ 本文の先頭の Backspace で上の項目に、末尾の `C-d` で下の項目をつなぐ
        - 閉じていないコードフェンスの中の Enter は、項目を分けずに改行を入れる
  - 構造を整える
    - `TAB` と `M-S-<right>` で字下げし、`<backtab>` と `M-S-<left>` で戻す
      - ^ `M-S-<up>` と `M-S-<down>` で、項目を上下へ動かす
        - ^ `C-c C-f` で折りたたむと、子の行が隠れ、バレットが変わる
          - ^ `C-c C-d` で、項目を子ごと消す
            - 他から参照される項目を消すときは、確認を尋ねる。断ると、何も消えない
  - 取り消す
    - v `C-/` で、打った文字や項目の分割を操作の順に取り消し、やり直せる
- 日々をたどる #利用者
  - // 出典: peta-journal-test.el, peta-journal-e2e.el, src/tests/shell.rs
  - タスクにする
    - v `C-c C-t` で項目がタスクになり、状態が `☐` `⊟` `☑` と変わる
      - ^ 状態の記号はバレットの後ろに付き、実行中の記号は大きく表示する
  - 日を移る
    - v `C-c C-n` で次の日へ、`C-c C-p` で前の日へ移り、`C-c C-j` で今日へ戻る
      - ^ `C-c C-x c` で Emacs のカレンダーを開き、日で `RET` を押すと、その日のジャーナルが開く
        - ^ カレンダーの `w`、`m`、`y` で、その日の週、月、年のページが開く
  - 片付ける
    - v `C-c C-x S` で、項目を子ごと、ページの最後の「# Stash」の見出しの下へ送る
- まとめて扱う #利用者
  - // 出典: peta-journal-test.el, peta-journal-e2e.el, src/tests/shell.rs
  - 複数の項目を選ぶ
    - vv `C-c SPC` で項目を子ごと選び、`n` と `p` や上下の矢印で選択を伸ばす
      - ^ 選ばれた行には選択の色が付き、`C-g`、`q`、`<escape>` で選択を終える
  - 選んだ項目を動かす
    - vv `M-S-矢印` と `TAB` で、選んだ項目をまとめて動かし、字下げする
      - ^ `d` や `DEL` で、選んだ項目をまとめて消す
        - ^ `w` と `M-w` で Markdown として kill ring にコピーし、`C-w` で切り取る
          - ^ 選択の中でも、`C-/` で取り消し、`C-?` でやり直す
  - 貼り付ける
    - vv `C-y` で、kill ring の先頭の文字を項目の貼り付けとして入れる
      - ^ クリップボードに画像だけがあるとき、`C-y` は画像をサーバーの assets に送り、カーソル位置にリンクを入れる
        - ^ `C-c C-x i` で選んだ画像ファイルを assets に送り、カーソル位置にリンクを入れる
          - ^ 読めないファイルや送信の失敗は、理由を表示し、本文は変えない
- ページで知識を整える #利用者
  - // 出典: peta-journal-test.el, peta-journal-e2e.el, src/tests/shell.rs, src/tests/emacs_text.rs
  - ページを開く
    - vvv `C-c C-s` で検索窓を開き、結果がページ、新しいページの作成、項目の順に並ぶ
      - ^ `C-n` と `C-p` で結果を選び、`RET` で開く。検索語の新しいページも、ここから作る
        - ^ 何も入力せずに `TAB` を押すと、最近のページが並ぶ
          - ^ `C-c C-o` やクリックで、ウィキリンクやタグのページを開く。Web のリンクはブラウザーで開く
            - ^ `C-c C-b` で前のページへ戻り、`C-c C-x f` で進む
              - ^ `C-c C-x s` のサイドバーに、フォルダの一覧、見出し、最近のページが並び、行からページを開く
                - ^ サイドバーの節を `TAB` で閉じると、次に起動した Emacs でも閉じている
                  - ^ `C-c C-x n` で、ページを新しいバッファに開き、別々のページを同時に編集する
  - ページを直す
    - vvv `C-c C-x r` で、ページの名前とフォルダを変える。同じ名前のページがあれば、上書きを尋ねる
      - ^ `C-c C-x D` で、下にページのない index ページを、フォルダの名前のページにする
        - ^ `C-c C-x d` で、確かめてからページを消し、今日のジャーナルを開く
          - ^ ジャーナル、ルートの index、アトラスでは、尋ねずに名前の変更を断る
  - プロパティを付ける
    - vvv `C-c C-x p` でプロパティの一覧を別の窓に開き、`s` で値を設定し、`d` で消す
      - ^ 値は、プロパティの定義の型で保存される
        - ^ 日時は `YYYY-MM-DD HH:MM` のローカル時刻で見え、まだ付いていないキーは現在時刻が初期値になる
          - ^ ジャーナルでは、尋ねずに断る
  - 項目をつなぐ
    - vvv `[[` と `]]` の間で `C-M-i` を押すと、ページ名を補完する
      - ^ `C-c C-x b` で、このページへリンクする項目の一覧をページごとに開く
        - ^ `C-c C-x w` で項目の参照を kill ring に入れ、`C-c C-x t` で今の項目をそのトランスクルージョンにする
          - ^ Web 版の「Copy Reference」の参照も、クリップボードを通して使える
            - ^ `C-c C-x T` で、トランスクルージョンをふつうの項目に戻す
  - 本文を読む
    - カーソルのない行は表示の形で描かれ、Markdown の記号が見えず、太字や見出しに色が付く
      - ^ カーソルのある行は、本文の Markdown を見せ、カーソルは同じ文字の位置に置かれる
        - ^ 見出し、リスト、引用、区切り線、コードブロックが、それぞれの見た目で描かれる
          - ^ 表の升は、全角を2と数えた幅で、列ごとにそろう
  - 画像を見る
    - vv 表示の形の行では、assets の画像が見える。カーソルのある行は、画像の代わりに Markdown を見せる
      - ^ リンクの `#w=` と `#h=` の大きさで見え、指定がなければウィンドウに収まる
        - ^ 取得できない画像や、画像を出せない環境では、代わりの文字のままでエラーにならない
          - ^ 画像の中身は、上限（`peta-journal-image-memory-limit`）までメモリに残す
- 設定とサーバーと付き合う #利用者
  - // 出典: peta-journal-e2e.el, tests/process.rs, src/tests/shell.rs, src/tests/timing.rs
  - サーバーの変化を受け取る
    - v Markdown ファイルや別のクライアントの変更は、開き直さなくてもバッファに出る
      - ^ 他からの変更で行が書き換わっても、カーソルは同じ項目の同じ位置に留まる
        - ^ つながりが切れると、つなぎ直す。サーバーが断ったときは、その理由が表示される
  - Emacs を閉じる
    - v Emacs を閉じても、打ったばかりの文字は保存される。サーバーが答えなければ、5秒で終わる
      - ^ 裏で動くプログラムが思いがけず止まると、モード行と警告で伝える

スライスのゴールは、次のとおりである。ウォーキングスケルトンは、今日のジャーナルを開いて書き、項目を分けて整え、表示の形で読める。毎日の記録は、タスク、日の移動、取り消し、Stash がそろい、サーバーの変化を受け取って安心して閉じられる。まとめて扱うは、項目を選んで動かし、kill ring とクリップボードでほかのページやアプリとやり取りし、貼った画像をその場で見る。知識の整理は、検索、リンク、サイドバー、複数のバッファでページを行き来し、名前、プロパティ、トランスクルージョンでページを整える。

スライスは、Emacs の利用者がこのアウトライナーを使い込んでいく順である。キーは、書きながら押すものを `C-c C-文字`、ページ全体の操作を `C-c C-x` のあとの1文字にそろえた。`C-c C-c` は、Emacs では「確定」の意味なので空けてある。PetaJournal 全体のストーリーマップは `docs/storymap-web.md` にある。Emacs 版には、アトラス、設定の画面、項目を別の日へ送る操作、外のプログラムとの連携はない。
