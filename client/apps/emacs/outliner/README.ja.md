# outliner-emacs

[English](README.md) | 日本語

PetaJournalのEmacs版フロントエンドである。次の2つからなる。

- `outliner-emacs`はRustのプログラムである。Cruxのコア（`client-core`）を持ち、HTTP、イベントストリーム、タイマーを実行する。
- `lisp/peta-journal.el`はEmacsのモードである。送られてきた行を描画し、利用者の操作を伝える。

両者は、stdinとstdoutのJSON Linesでやり取りする。メッセージは`src/protocol.rs`で定義している。

## セットアップ

プログラムをビルドする。

```powershell
cd peta-journal/client
cargo build --release -p outliner-emacs
```

このフォルダーの`release.ps1`も同じことをする。macOSとLinuxでは`release.sh`を使う。`debug.ps1`と`debug.sh`は開発用である。デバッグビルドを作り、今日のジャーナルを開いたEmacsを起動する。

Emacsの初期設定ファイルに、次の内容を追加する。

```elisp
(add-to-list 'load-path "<peta-journal>/client/apps/emacs/outliner/lisp")
(autoload 'peta-journal "peta-journal" nil t)
```

ジャーナルサーバーを起動した状態で、`M-x peta-journal`を実行する。今日のジャーナルが開く。

モードは、`exec-path`、`target/release`、`target/debug`の順にプログラムを探す。別のプログラムを使うときは、`peta-journal-shell-program`を設定する。Emacs 29.1以降が必要である。

### ビルドし直したとき

PetaJournalのバッファを`C-x k`ですべて閉じ、`M-x peta-journal`を実行し直す。動いているプログラムは、バッファを閉じるまで古いままである。

`exec-path`の上（たとえば`~/.local/bin`）にプログラムのコピーがあると、モードはそちらを先に使う。ビルドしても古いコピーが動き続けるので、新しい機能が出ないときは、これを疑う。

### ビルドを外付けのディスクに置くとき

`client/target`を外付けのディスクへのシンボリックリンクにすると、ディスクを外したときに、モードはプログラムを見つけられない。外付けのディスクには、ビルドの中間生成物だけを置く。Cargo 1.91からの`build.build-dir`を、環境変数か`~/.cargo/config.toml`で指定する。

```sh
export CARGO_BUILD_BUILD_DIR='/Volumes/<ディスク>/rust-target/build/{workspace-path-hash}'
```

プログラムは`target/release`に残るので、ディスクを外しても、モードはプログラムを見つけられる。

### 別のサーバーを使う

接続先は、既定で`http://localhost:8087`である。別のサーバーを使うときは、Emacsの初期設定ファイルに次の内容を追加し、そのサーバーのアドレスを書く。

```elisp
(setq peta-journal-server "http://localhost:18087")
```

今のセッションだけ変えるときは、`M-:`を押して同じ式を入力する。

この設定は、シェルの起動時にだけ効く。すでにPetaJournalを開いているときは、`C-x k`でそのバッファをすべて閉じる。シェルも一緒に止まる。そのあとで、`M-x peta-journal`を実行し直す。

## 編集

ページ全体が1つのバッファに入る。本文は、他のバッファと同じように入力する。`[[`を打つと`]]`が補われ、続けて`]]`を打つとその上を進む。行頭でバッククォートを3つ打つと、閉じるコードフェンスが補われる。バレットと項目の間の改行は、読み取り専用である。アウトラインは、次のキーでだけ変わる。

| キー | 動作 |
|---|---|
| `RET` | 項目を分割する、または下に項目を追加する |
| `S-RET`、`C-j` | 項目の中で改行する |
| `TAB`、`M-S-<right>` | 字下げする |
| `<backtab>`、`M-S-<left>` | 字下げを戻す |
| `M-S-<up>`、`M-S-<down>` | 項目を上下に動かす |
| 本文の先頭で`DEL` | 上の項目につなぐ |
| 本文の末尾で`C-d` | 下の項目をつなぐ |
| 本文の末尾で`C-k` | 下の項目をつなぐ |
| `C-c C-t` | タスクの状態を切り替える |
| `C-c C-f` | 子項目を隠す、または表示する |
| `C-c C-d` | 項目を子項目ごと削除する |
| `C-c SPC` | 項目を子項目ごと選択する。複数の項目をまとめて操作できる |
| `C-c C-x w` | 項目の参照（id）をコピーする |
| `C-c C-x t` | コピーした参照の項目を、トランスクルージョンとして貼る |
| `C-c C-x T` | トランスクルージョンを、ふつうの項目に戻す |
| `C-c C-x S` | 項目を子項目ごと、ページの最後の`# Stash`の見出しの下へ送る |
| `C-/`、`C-?` | コアの履歴で、元に戻す、やり直す |
| `C-x C-s` | すぐに保存する |

`M-<right>`などの`M-`と矢印のキーは、Emacsの単語の移動などに残している。

本文は、入力が止まると自動でも保存される。Emacsが`peta-journal-idle-finish-seconds`の間なにもしないと、項目の編集は終わる。編集の間、コアはファイルの変更を取り込まないためである。

次のキーで、他の場所へ移る。

| キー | 動作 |
|---|---|
| `C-c C-j` | 今日のジャーナルを開く |
| `C-c C-s` | 検索窓を開く |
| `C-c C-n`、`C-c C-p` | 次または前のジャーナルを開く |
| `C-c C-b` | 前のページへ戻る |
| `C-c C-o` | カーソル位置のウィキリンクやタグを開く |
| `C-M-i` | `[[`の中で、ページの名前を補完する |

ページ全体に対する操作は、`C-c C-x`のあとに1文字を押す。

| キー | 動作 |
|---|---|
| `C-c C-x s` | 左のサイドバーを開く、または閉じる |
| `C-c C-x r` | ページの名前か、indexページのフォルダの名前を変える |
| `C-c C-x D` | indexページを、フォルダの名前のページにする |
| `C-c C-x d` | ページを消す |
| `C-c C-x p` | ページのプロパティの一覧を開く、または閉じる |
| `C-c C-x n` | ページを名前で新しいバッファに開く |
| `C-c C-x i` | カーソル位置に画像ファイルを挿入する |
| `C-c C-x b` | このページのバックリンクを一覧する |
| `C-c C-x f` | 戻る前のページへ進む |
| `C-c C-x c` | カレンダーで日付を選んで開く |

ページを名前で開くには、検索窓を使う。

## サイドバー

`C-c C-x s`または`M-x peta-journal-sidebar`で、フレームの左端にサイドバーが開く。もう一度押すと閉じる。幅は`peta-journal-sidebar-width`で変えられる。既定値は`30`である。

中身はWeb版のサイドバーと同じ順に並ぶ。Web版のカレンダーは入れない。Emacsでは`C-c C-x c`でカレンダーを開くためである。

- 今のページのフォルダのページ。見出しはフォルダの名前で、そのindexページを開く。`../`は親のフォルダを開く。今のページには色が付く
- Contents：ページの見出し。段の深さだけ字下げする
- Recent Pages：最近のページ

行の上で`RET`を押すか、行をクリックすると、そのページが開く。見出しの行では、ページのその項目へカーソルが移る。サイドバーは、ページが変わると描き直される。

節の中のどの行でも`TAB`を押すと、その節は見出しだけになる。もう一度押すと開く。見出しの前の`▾`と`▸`をクリックしても、同じである。閉じた節は`peta-journal-sidebar-collapsed`に保存されるので、次に起動したEmacsでも閉じたままである。

## ウィキリンクの補完

`[[`と`]]`の間で`C-M-i`を押すと、ページの名前が補完される。Emacsの標準の補完（`completion-at-point`）である。CorfuやCompanyのような補完の画面を使っていれば、候補はそこに出る。

- 候補は、`[[`と`]]`の間の文字でサーバーが探したページである。名前の先頭が合うものに限らない。フォルダの名前や、名前の中の語でも見つかる。並びはサーバーの順のままで、多くても10件である。
- 候補が1つなら、すぐにその名前が入る。いくつもあれば、一覧から選ぶ。
- 何も打たずに押すと、最近のページが候補になる。
- 選んだ名前は、`[[`と`]]`の間の全体と入れ替わる。カーソルは`]]`の前に残る。
- Emacsだけなら、候補が出るのはキーを押したときだけである。打っている間に、勝手には出ない。

## カレンダー

`C-c C-x c`または`M-x peta-journal-calendar`で、Emacsのカレンダーが開く。カレンダーのいつものキーで日を選ぶ。次のキーが加わる。

| キー | 動作 |
|---|---|
| `RET` | カーソルの日のジャーナルを開く |
| `w` | カーソルの日の週のページを開く |
| `m` | カーソルの日の月のページを開く |
| `y` | カーソルの日の年のページを開く |

カレンダーを開くと、これらのキーの案内がエコーエリアに出る。どのキーも、カレンダーを閉じてからページを開く。`q`は、何も開かずにカレンダーを閉じる。

週の数え方（USかISO）は、サーバーの設定に従う。カレンダーの週の始まりの曜日は、Emacsの`calendar-week-start-day`で決まり、サーバーの設定には合わせない。ISOの週を使うなら、`(setq calendar-week-start-day 1)`で月曜始まりにするとよい。

`M-x calendar`でふつうに開いたカレンダーには、これらのキーは付かない。

## 項目の間の隙間

項目の間の隙間は、`peta-journal-item-gap`で変えられる。単位はピクセルで、既定値は`4`である。`0`にすると隙間はなくなる。変えた値は、次に描かれた行から効く。隙間が出るのはGUIのEmacsだけである。

## 項目を選択する

`C-c SPC`または`M-x peta-journal-select`で、点のある項目を子項目ごと選択する。その項目の編集は終わる。選択の間、選ばれた行にはリージョンの色が付く。バッファは`peta-journal-selection-mode`になり、文字は変えられない。次のキーは、選んだ項目のすべてに効く。

| キー | 操作 |
|---|---|
| `n`、`C-n`、`<down>`、`S-<down>` | 下の項目を加える。または、一番上の項目を外す |
| `p`、`C-p`、`<up>`、`S-<up>` | 上の項目を加える。または、一番下の項目を外す |
| `M-S-<up>`、`M-S-<down>` | 項目を上下に動かす |
| `TAB`、`M-S-<right>` | 項目を字下げする |
| `<backtab>`、`M-S-<left>` | 項目の字下げを戻す |
| `d`、`DEL`、`C-d`、`<delete>` | 項目を子項目ごと削除する |
| `w`、`M-w` | 項目のMarkdownをkill ringに入れる |
| `C-w` | Markdownをkill ringに入れて、項目を削除する |
| `C-/`、`C-?` | 元に戻す、やり直す |
| `C-g`、`q`、`<escape>` | 選択を終える |

選んだ項目を削除したときも、選択は終わる。

## トランスクルージョン

トランスクルージョンは、別の項目を子ごと見せる項目である。作るには、見せたい項目で`C-c C-x w`を押して、参照をコピーする。それから、見せる側の項目で`C-c C-x t`を押す。参照は項目のidで、kill ringに入る。Web版の「Copy Reference」がコピーした参照も、クリップボードを通して使える。idでない文字を貼っても、何も起きない。

`C-c C-x T`で、トランスクルージョンをふつうの項目に戻す。切れたトランスクルージョンも戻せる。ふつうの項目では、尋ねずに断る。

## ページの名前を変える

`C-c C-x r`または`M-x peta-journal-rename-page`で、今のパスを初期値にして新しい名前を尋ねる。名前の中の`/`はフォルダの区切りである。`/`のない名前を付けると、ページはフォルダの外へ出る。同じ名前のページがあれば、上書きするかをEmacsが尋ねる。

indexページでは、代わりにフォルダの新しいパスを、今のパスを初期値にして尋ねる。indexページは、新しいフォルダへ移る。ジャーナル、ルートのindex、アトラスの名前は変えられない。そこでは、尋ねずに断る。

`C-c C-x D`または`M-x peta-journal-demote-index`で、indexページをフォルダの名前のページにする。たとえば、`work/memo/`のindexページは、`work/memo`のページになる。先にEmacsが尋ねる。ページにできるのは、下にページのないindexページだけである。ほかのページでは、尋ねずに断る。

## ページを消す

`C-c C-x d`または`M-x peta-journal-delete-page`で、今のページをファイルごと消す。先に、ページの名前を挙げてEmacsが尋ねる。消したあとは、今日のジャーナルが開く。今日のジャーナルそのものは消さない。そこでは、コマンドは何もしない。

## 画像を挿入する

`C-c C-x i`または`M-x peta-journal-insert-image`で、ファイルを尋ねる。サーバーがノートの`assets`フォルダに複製を置き、カーソル位置にそのリンクが入る。

複製の名前はサーバーが付ける。日時とランダムな文字でできたID（HMTID）に、元の拡張子を付けた名前である。元の名前は、リンクの文字に残る。たとえば、`構成図.png`を挿入すると、`![構成図.png](../assets/20261110090501_QZ998PX.png)`が入る。名前の日時はUTCである。

50MBを超えるファイルはサーバーが断る。そのときはEmacsが理由を表示し、本文は変わらない。

### クリップボードの画像を貼り付ける

スクリーンショットなどの画像をクリップボードに入れて、`C-y`を押す。画像はサーバーに送られ、カーソル位置にそのリンクが入る。貼り付けた画像には元の名前がないので、リンクの文字は`image.png`になる。

- 画像が貼り付けられるのは、クリップボードに画像があり、文字がないときだけである。文字もあれば、今までどおり文字が貼り付けられる。
- Emacsが、クリップボードの画像をPNGとして取り出せることが要る。Windowsでは、Emacs 31からである。Emacs 30までのWindowsでは、`C-y`は今までどおり文字だけを貼り付ける。確かめたのは、WindowsのEmacs 31.1だけである。

## 画像を見る

カーソルのない項目では、`![名前](../assets/ファイル名)`のリンクの代わりに画像が見える。`![名前](https://example.com/file.png)`のような、サーバーの外にある画像も見える。Webブラウザーと同じく、EmacsがそのURLから取得する。カーソルのある項目では、リンクの文字が見える。カーソルが項目を出ると、画像に戻る。画像は表示だけで、本文の文字は変わらない。

画像はウィンドウに収まる大きさになる。ウィンドウの大きさが変わると、合わせ直す。リンクに`#w=300&h=240`があれば、その大きさを使う。Emacsの画像の倍率（`image-scaling-factor`）は、ここにもかかる。

次の場合は、リンクは文字のままである。

- ターミナルのEmacsのように、画像を出せない環境
- サーバーから取得できないファイルと、Emacsが読めない形式のファイル。PNGをまったく表示できないEmacsのビルドもある
- コードの中のリンク
- サーバーの`assets`も、`http://`や`https://`のURLも指さないリンク
- `assets`のファイル名に、ASCIIの英数字と`.`、`_`、`-`以外の文字があるリンク

画像はサーバーから取得する。入力を止めないよう、取得を待たずに進み、届いたときに表示する。取得できなかった画像は、別のページを開いたときにもう一度取得する。取得した中身は、`peta-journal-image-memory-limit`（64MB）までメモリに残る。上限を超えると、開いているページがリンクしていない画像を、使ってから長いものから忘れる。忘れた画像は、ページが表示するときにもう一度取得する。

## ページのプロパティ

`C-c C-x p`で、ページのプロパティの一覧を別の窓に開く。カーソルは一覧の最初のプロパティに移る。ページの窓でもう一度押すと、一覧を閉じる。

一覧の中では、次のキーを使う。

| キー | 動作 |
|---|---|
| `s` | プロパティを設定する。キーと値を尋ねる |
| `d` | プロパティを削除する。削除するキーを尋ねる |
| `q` | 一覧を閉じる |
| `n`、`p` | 次または前の行へ移る |

`s`と`d`は、カーソルの行のキーを既定値にして尋ねる。そのまま`RET`を押せば、その行のプロパティが対象になる。設定や削除のあとも、カーソルは同じ行に残る。

一覧と補完は、キーを名前の本体と型で見せる。たとえば、キー`rating_n`は`rating (number)`と見える。本体が同じキーも、これで区別できる。キーは、サーバーのプロパティ定義から補完する。新しいキーは、ここではなくWeb版の設定で定義する。リストの値はコンマで区切る。`M-x peta-journal-set-property`と`M-x peta-journal-delete-property`でも、同じことができる。

日時は`YYYY-MM-DD HH:MM`のローカル時刻で表示され、同じ形で入力する。サーバーにはUTCで保存される。まだ付いていないキーは現在時刻が初期値なので、`RET`だけで確定できる。

ジャーナルにはプロパティを付けられないので、ジャーナルでは一覧を開かずに断る。

## 2つのページを同時に編集する

`C-c C-x n`または`M-x peta-journal-new-buffer`で、ページを新しいバッファに開ける。どちらのページも編集できる。名前を空にすると、今日のジャーナルが開く。バッファごとに、シェルとUndoの履歴が別になる。バッファを閉じても、止まるのはそのバッファのシェルだけである。

そのページを表示中のバッファがあれば、このコマンドはそのバッファへ移る。ページへ移る他のキーでは、1つのページが2つのバッファに表示されることがあり、そのときはEmacsが警告する。この状態は避けること。バッファはそれぞれ別のクライアントなので、片方で保存した内容はもう片方にも表示される（[ADR 015](../../../../docs/adr/adr-015-client-id-on-every-change-request.md)）。ただし、編集中のバッファは、編集が終わるまで読み直しを待つ。同じ項目を2つのバッファで編集すると、編集が互いを上書きするおそれがある。

## 検索窓

`C-c C-s`を押して、ミニバッファに入力する。結果は下の窓に表示され、入力に合わせて変わる。結果には、ページ、新しいページを作る項目、項目が並ぶ。

| キー | 動作 |
|---|---|
| 何も入力せずに`TAB` | 最近のページを並べる |
| `C-n`、`<down>` | 次の結果を選ぶ |
| `C-p`、`<up>` | 前の結果を選ぶ |
| `RET` | 選んだ結果を開く |
| `C-g` | 検索窓を閉じて、今のページに留まる |

これらのキーは、入力の直後に押してよい。入力した語の結果が届くのを待ってから動く。

最近のページは、更新の新しい順に、ドキュメントページを10件まで並べる。並んだあとで文字を入力すると、ふつうの検索結果に戻る。

どのバッファからでも検索窓を開くには、Emacsの初期設定ファイルに次の内容を追加する。`C-c`と英字1文字のキーは、ユーザーのために空けてあるキーである。

```elisp
(autoload 'peta-journal-search "peta-journal" nil t)
(global-set-key (kbd "C-c s") #'peta-journal-search)
```

## テスト

`cargo test -p outliner-emacs`は、2種類のテストを動かす。

- `src/tests/`は、偽のホストを使って、コアを動かすシェルをテストする。
- `tests/process.rs`は、プログラムそのものを起動する。テストがEmacsの代わりに標準入力と標準出力でやり取りし、テストの中の小さなサーバーがHTTPの要求に答える。Emacsもjournal-serverもいらない。このうち1件は、シェルがサーバーをあきらめるまでの5秒を待つ。

`cargo cov`は、この両方を測る（`BUILD.md`を参照）。CIは、この両方と、下のバッファのテストと、E2Eテストを動かす。E2Eテストは、Linuxの専用のジョブ（`emacs-e2e`）で動かす。

バッファのテストは、プロセスなしで動く。

```powershell
cd peta-journal/client/apps/emacs/outliner
emacs -Q --batch -L lisp -l lisp/test/peta-journal-test.el -f ert-run-tests-batch-and-exit
```

E2Eテストは、実際のキー入力、本物のシェル、本物のサーバーを使う。モード、シェル、サーバーをつないだ全体という、他のテストでは動かせない部分を動かす。先に両方のプログラムをビルドする。各テストは、ポート18087でサーバーを起動する。サーバーのファイルは、すべて一時フォルダに置く（`--throwaway-dir`）。サーバーの報告するMarkdownフォルダが一時フォルダの外なら、テストは止まる（ADR-002を参照）。`PETA_E2E_SERVER`が設定されていなければ、テストはスキップされる。

```powershell
$env:PETA_E2E_SERVER = "<peta-journal>\journal\target\debug\journal-server.exe"
emacs -Q --batch -L lisp -L lisp/test -l lisp/test/peta-journal-e2e.el -f ert-run-tests-batch-and-exit
```

Windowsでは、`emacs`は本物の`emacs.exe`でなければならない。`emacsclient`のラッパーは使えない。

### 整形

フォーマッターは、ほかのプロジェクトと共有する[elisp-formatter](https://github.com/sosuisen/elisp-formatter)である。`emacs-lisp-mode`の字下げでファイルを整える。字下げは空白で行い、タブは使わない。行の終わりの空白も消す。そのため、EmacsのTABと同じ字下げになる。CIは、タグ`v0.1.0`を取ってきて、整形されているかを確かめる。

字下げは、Emacsの版で変わる。たとえば、`'(...)`のplistの字下げは、Emacs 30と31で違う。そのため、整形はEmacs 31で行う。CIも、snapのEmacs 31を使う。

- マクロは、その`declare (indent ...)`に従って字下げする。新しいマクロには、これを書く。
- 記号を並べた`'(...)`のリストは、最初の記号だけを1行目に置く。残りがその下に揃う。

elisp-formatterを好きな場所に一度cloneし、このフォルダーから回す。

```powershell
emacs -Q --batch -l <elisp-formatter>/elisp-formatter.el -f elisp-formatter-write lisp   # ファイルを整形する
emacs -Q --batch -l <elisp-formatter>/elisp-formatter.el -f elisp-formatter-check lisp   # 何も変えず、整形が要れば失敗する
```
