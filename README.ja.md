# PetaJournal — the headless outliner

<br>

[English](README.md) | 日本語

PetaJournalは、アウトライナー、付箋、タスク管理などのノートアプリを、自分のPC上のジャーナルサーバーを中心にゆるくつなぐ、オープンな環境です。

## 機能

- ネットワークにつながっていなくても使えます。ジャーナルサーバーは自分のPCで動きます。
- ノートはアウトライナー向けのMarkdown形式で保存されます。
- ノートはDropboxを使って複数台のPCやスマートフォンで同期できます。
- 複数のノートアプリが、共通の基盤の上で動作します。好みのアプリを追加していきましょう。
